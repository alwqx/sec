# 国家统计局宏观数据采集

## NBS 的含义

`NBS` 是 **National Bureau of Statistics** 的缩写，即中国国家统计局。`provider/nbs` 按数据来源命名，与 `provider/sina`、`provider/eastmoney` 一致，仅负责国家统计局数据的请求、解析和缓存。

- 国家统计局官网：<https://www.stats.gov.cn/>
- 官方数据发布库：<https://data.stats.gov.cn/>
- 新版月度查询页面：<https://data.stats.gov.cn/dg/website/page.html#/pc/national/monthData>
- CPI 编制方法：<https://www.stats.gov.cn/zs/tjws/zytjzbqs/jmxxggzs/202411/t20241127_1957589.html>

## 当前范围与用法

目前支持全国月度 CPI、核心 CPI（不包括食品和能源）、PPI（工业生产者出厂价格指数），分别查询同比与环比口径；另支持制造业 PMI、非制造业商务活动指数及相关分项、规模以上工业增加值增速、社会消费品零售总额和城镇调查失业率，口径见下文。暂不涉及 US、汇率、股票与黄金的联合分析，也未接入 Desktop。

```bash
sec macro cn cpi
sec macro cn core-cpi
sec macro cn ppi

sec macro cn cpi --begin 202001 --end 202609
sec macro cn core-cpi --begin 202601 --end 202609 --json
sec macro cn ppi --refresh
sec macro cn cpi --no-cache
```

- 月份参数为 `YYYYMM`；默认截至上一个自然月，开始月份默认为截至月份前 11 个月。
- 上个月的数据可能尚未发布，输出只包含接口实际返回的月份，不将缺失月份填为零。
- `--json` 输出原始指数、衍生涨跌幅、地区、指标、月份、比较口径、目录 ID、指标 ID、官方指标名称、来源和抓取时间；缺失数值为 `null`。
- `--refresh` 跳过现有缓存并重新采集；`--no-cache` 完全禁用磁盘缓存。
- 核心 CPI 使用独立指标，不以“非食品 CPI”替代。核验时 2021—2025、2026 年起的目录包含该指标，2016—2020 目录未提供。此类历史缺口输出空值，并在 `note` / 表格说明列标记“该历史目录未提供核心 CPI 指标”；这不表示当时没有发布过核心 CPI。

## 新版接口

2026-10-26 核验时，官网已迁移到新版发布库，旧版 `easyquery.htm` 在当前环境返回 HTTP 403。本实现沿用官方新版页面发出的请求，不依赖旧版 `A0101` 等指标编码。

接口基址：

```text
https://data.stats.gov.cn/dg/website/publicrelease/web/external
```

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/new/queryIndexTreeAsync?code=1&pid=...` | 发现月度数据、价格指数和历史分段目录；根目录省略 pid |
| GET | `/new/queryIndicatorsByCid?cid=...&pageSize=1000` | 获取目录下的指标元数据，精确匹配总体/核心指标及比较口径 |
| POST | `/stream/esData` | 获取全国月度观测值，读取完整响应后解析 JSON |

数据请求体结构：

```json
{
  "cid": "所选目录 ID",
  "rootId": "价格指数目录 ID",
  "indicatorIds": ["所选指标 ID"],
  "daCatalogId": "",
  "das": [{"text": "全国", "value": "000000000000"}],
  "dts": ["202601MM-202609MM"],
  "showType": 1
}
```

月份必须带 `MM` 后缀。CPI 目录按 `(-2015)`、`(2016-2020)`、`(2021-2025)`、`(2026-)` 等区间分段；程序动态发现目录，只查询与所选时间范围相交的分段。即使底层序列返回了目录区间之外的数据，也按分段范围裁剪，避免重复月份。目录/指标结构改变、指标列表被截断、重复观测或无效数值均返回错误，不把部分结果当完整结果输出。

这些是官网使用的接口，并非具有版本兼容承诺的公开开发者 API；目录名称或响应结构变化时需要重新核验。

## 统计口径

| `basis` | 原始指数含义 | `change_percent` |
| --- | --- | --- |
| `上年同月=100` | 同比相对指数 | 原始指数减 100，单位 % |
| `上月=100` | 环比相对指数 | 原始指数减 100，单位 % |

例如原始指数 `100.9` 对应涨幅 `0.9%`，不是涨幅 `100.9%`。这两类相对指数也不是可直接计算长期累计价格变化的固定基期指数。本实现未进行季节调整，不计算环比年化，不混用“上年同期=100”的累计口径。

部分官方元数据将同比指数单位标为 `%`，仍以官方指标名称中的比较基准解释其数值，不直接视为百分比增速。历史分段的分类与权重可能变化，输出保留目录与序列标识，供后续分析追溯。

接口中的 `null`、空字符串、`--` 等缺失标记转为 `nil`，真实 `0` 保留为数值。没有返回的月份不插值；返回月份缺少所选全国指标时保留空值。

## 缓存与时间信息

缓存位于 `~/.sec/cache/nbs/`，按请求地址与请求体的 SHA-256 存储，六小时内复用。缓存含完整原始 JSON 响应与抓取时间，写入使用临时文件加原子重命名；失败请求不覆盖成功缓存。

当前采用按查询范围缓存、过期后重新获取的策略，**尚未实现按序列增量合并、修订版本归档或公布日历**。刷新同一个请求会替换它的旧缓存。

`period` 是数据所属月份，`fetched_at` 是实际抓取时间（UTC），缓存命中时保留原抓取时间。接口未返回逐条公布时间，程序不将所属月份、元数据中的日期范围或抓取时间伪装成公布时间。本版本不支持重建“历史某日当时已知的数据”，不能据此开展无前视偏差的回测。

## 制造业 PMI

`PMI` 是 Purchasing Managers' Index（采购经理指数）的缩写。`pmi` 命令采集全国制造业总指数和四个指定分项；非制造业商务活动指数使用下文的独立命令，综合 PMI 尚未接入。

```bash
sec macro cn pmi
sec macro cn pmi --begin 202001 --end 202609
sec macro cn pmi --begin 202607 --end 202609 --json
sec macro cn pmi --refresh
sec macro cn pmi --no-cache
```

月份默认范围、缓存目录、六小时有效期和刷新方式与价格查询一致。终端每个月展示一行，含总指数、生产、新订单、新出口订单、从业人员五列；JSON 每个月输出五条观测记录。

| JSON `indicator` | 官方指标 | 含义 |
| --- | --- | --- |
| `manufacturing-pmi` | 制造业采购经理指数 | 制造业总体景气 |
| `production` | 生产指数 | 生产活动 |
| `new-orders` | 新订单指数 | 新增需求 |
| `new-export-orders` | 新出口订单指数 | 出口订单需求 |
| `employment` | 从业人员指数 | 企业用工变化 |

采集流程为“月度数据 → 采购经理指数 → 制造业采购经理指数 → 指标元数据 → 五项全国观测值”。动态查找目录和指标 ID，并在同一数据请求中提交五个 ID。不会误选非制造业或综合 PMI，也不自动扩展到其余分项。

PMI 是扩散指数，以百分数形式发布，取值范围为 0—100。官方数据已经季节调整，JSON 显式返回 `unit: "%"` 和 `seasonally_adjusted: true`。50 是临界点，大于/小于 50 表示相应调查活动相对上月扩张/收缩，**不表示产出同比或环比增长了该百分比**。它不适用价格指数的“减 100”转换；本次也不计算月差或经济状态评分。方法和季调说明见[国家统计局 PMI 发布说明](https://www.stats.gov.cn/sj/zxfb/202609/t20260930_1965449.html)。

JSON 保留全国地区、指标键、所属月份、原始指数、官方目录/序列标识、名称、来源和抓取时间。缺失分项输出 `null`，表格显示 `—`；整个月未返回时不生成虚构数据。重复月份/观测值、非法或超出 0—100 的数值、元数据缺少必需指标、指标列表被截断时返回错误。公布时间和历史修订归档限制与上文一致。

采购经理调查 JSON 增加 `survey` 字段：制造业为 `manufacturing`，非制造业为 `nonmanufacturing`。同名分项（如 `new-orders`）应结合 `region`、`survey`、`indicator`、`period` 识别，不能跨调查合并为同一序列。制造业原有指标键和数值不变。

`pmi-catalogs.json`、`pmi-series.json`、`pmi-values.json` 是 2026-10-26 从官方接口取得并精简的测试样本，数据样本覆盖 2026 年 7—9 月。测试覆盖五项正确映射、月份排序/过滤、零值与缺失值、无效/重复响应、缓存命中与刷新、CLI 月份校验和中文表格展示。

## 非制造业商务活动指数

```bash
sec macro cn nonmanufacturing-pmi
sec macro cn npmi --begin 202001 --end 202609
sec macro cn npmi --begin 202607 --end 202609 --details
sec macro cn npmi --json
sec macro cn npmi --refresh
sec macro cn npmi --no-cache
```

`npmi` 是 `nonmanufacturing-pmi` 的别名。默认展示全国非制造业、服务业、建筑业三个商务活动指数；`--details` 额外展示九个全国分项，避免默认表格过宽。采集范围与显示方式无关，JSON 总是输出每月全部 12 项；月份参数和缓存控制与制造业命令一致。

| JSON `indicator` | 官方指标 |
| --- | --- |
| `business-activity` | 非制造业商务活动指数 |
| `services-business-activity` | 服务业商务活动指数 |
| `construction-business-activity` | 建筑业商务活动指数 |
| `new-orders` | 新订单指数 |
| `new-export-orders` | 新出口订单指数 |
| `outstanding-orders` | 在手订单指数 |
| `inventory` | 存货指数 |
| `input-prices` | 投入品价格指数 |
| `selling-prices` | 销售价格指数 |
| `employment` | 从业人员指数 |
| `supplier-delivery-times` | 供应商配送时间指数 |
| `business-expectations` | 业务活动预期指数 |

程序动态选择“采购经理指数 → 非制造业采购经理指数”目录，精确匹配全部 12 个指标后一次请求全国数据；不复用制造业的同名分项。九个分项反映非制造业全国总体，**不是服务业和建筑业各自的订单、价格或就业分项**；当前目录没有提供后者，不从新闻文本拼接或用全国值替代。

各项均保留官方季调扩散指数水平（`unit: "%"`、`seasonally_adjusted: true`），不计算“指数减 100”。50 为临界点，但解释取决于指标：投入品价格、销售价格高于 50 表示价格上升，供应商配送时间高于 50 表示交货加快，不能统一解释为经济增长加快。总指数来自官方，不使用服务业和建筑业数值的简单平均。统计说明参考[国家统计局发布](https://www.stats.gov.cn/sj/zxfb/202609/t20260930_1965449.html)。

如果某个月服务业、建筑业或其他分项缺失，该分项保持 `null`，不使用总指数补值，也不补齐缺少的整月。遇到元数据缺少必需指标、重复记录或非法数值时返回错误，避免输出貌似完整的部分结果。缓存、原始响应追溯和历史版本限制沿用上文约定。

2026-10-26 对 2020 年 1 月至 2026 年 9 月的真实查询验证得到 81 个月、972 条观测：其中 2020 年服务业、建筑业商务活动指数各缺 12 个月，共 24 条空值，其余观测有值。这是当前发布库的返回情况，不代表对应历史指标从未发布，也不承诺未来刷新仍有相同覆盖范围。

`nonmanufacturing-series.json`、`nonmanufacturing-values.json` 为 2026-10-26 获取并精简的官方元数据与 2026 年 7—9 月观测样本。测试验证 12 项映射、调查类型隔离、服务业缺失处理、零值、缓存与刷新、别名/月份校验，以及默认总览和明细输出。

## 规模以上工业增加值

```bash
sec macro cn industrial
sec macro cn ip --begin 202601 --end 202609
sec macro cn industrial --begin 202001 --end 202003 --json
sec macro cn ip --refresh
sec macro cn ip --no-cache
```

本功能采集全国总量增速，不扩展到经济类型、三大门类、行业或产品产量。`ip` 为 `industrial` 的别名，月份默认范围、JSON、缓存和刷新参数与其他宏观命令一致。

### 数据来源与口径

发布库路径为“月度数据 → 工业 → 规上工业增加值增长速度”，动态发现目录和指标 ID，一次查询两个指标：

| JSON 字段 | 官方指标 | 解释 |
| --- | --- | --- |
| `yoy_percent` | 规上工业增加值同比增长 | 单月实际同比增速；未提供时为 `null` |
| `ytd_percent` | 规上工业增加值累计增长 | 年初至该月的实际累计同比增速 |
| `ytd_period` | 程序显式标注累计所属期 | 如 `202601-202602`，不代表单独 2 月 |
| `mom_percent` | 发布稿中的环比增速表 | 季调后的实际单月环比增速 |

所有数值已是增速，单位 `%`，不执行“减 100”转换。`price_basis: "real"` 表示扣除价格因素；`mom_seasonally_adjusted: true` 仅描述环比，不将同比或累计同比标为季调。统计范围和可比基数可能变化，不通过历史总额自行推导官方增速。方法、1—2 月合并发布和环比修订说明见[国家统计局发布稿](https://www.stats.gov.cn/sj/zxfb/202603/t20260316_1962782.html)。

2026 年 1 月的同比、累计同比均为空，2 月单月同比为空，1—2 月累计同比为 6.3%；两个月各自的季调环比可单独发布。程序保留这些原始缺口，在 2 月标注“1—2月合并累计，非2月单月同比”，不将累计值复制成单月同比，不将 1—2 月拆分，也不通过累计增速相减计算单月增速。历史年份按接口实际返回保留，不对所有 1、2 月强行覆盖数值。

### 季调环比补充与历史限制

当前结构化发布库只提供同比与累计指标。环比通过以下官方来源补充：

1. 分页请求 `/new/queryCMSArticles?code=zxfb&pagenum=...&pageSize=100`，筛选规模以上工业增加值月报，兼容“9月份”和“1—4月份”等标题。
2. 从新到旧查找可能覆盖所选月份的月报，读取其 `https://www.stats.gov.cn/` 原文。
3. 解析“环比增速”表，处理跨行年份、负值、零值和桌面/移动页面重复表格。同月存在冲突值时返回错误。
4. 各月份采用首先检索到的最新可用修订，保留它自己的来源和时间；不把旧稿覆盖到已取得的新修订上。

检索以月报常见的本月及此前 12 个月修订窗口为候选范围。发布列表按其 `pb_time` 排序，`mom_published_at` 保存该列表标注的北京时间；这是官方列表元数据，可能与原文页面标注的时间不同。`mom_fetched_at` 是环比发布稿实际抓取时间，`fetched_at` 是发布库数据抓取时间，两者在命中缓存时均保持原值。发布库没有逐条公布时间，不将环比发布稿时间套用到同比和累计数据。

官方发布稿列表不是完整历史档案。2026-10-26 核验时，2026 年 1—9 月三类增速均可按实际发布情况取得；2020 年 1—3 月同比/累计数据可查询，但列表未覆盖足够早的环比修订表，`mom_percent` 保留 `null` 并标注“官方可检索发布稿未提供该月季调环比”。这不表示对应月份从未发布环比，也不承诺其他查询范围都有完整环比覆盖。缺少整月时不生成虚构记录；若结构化接口返回该月空行，则保留空值。

查询需要同时访问数据发布库与官方发布稿。网络、HTTP 或表格解析失败会返回错误，避免把失败误报为无数据；列表正常检索结束但没有覆盖对应月份时才保留缺失说明。发布稿最多检索 100 页，超过上限提示缩小范围。发布稿原始 HTML 以 JSON 字符串保存在同一 NBS 缓存目录，沿用六小时有效期及原子写入，不覆盖已存数据为失败页面。本功能仍未提供完整修订档案，不能用于无前视偏差的历史回测。

测试样本 `industrial-*.json` 及 `industrial-release.html` 取自 2026-10-26 的官方响应，已精简字段/HTML 样式；环比样本保留了重复表格。测试覆盖 1—2 月口径、零值/负值、缺失值、跨年环比表、重复/冲突检测、最新可用修订优先、发布稿分页、缓存命中/刷新、无效链接与命令参数。

## 社会消费品零售总额

```bash
sec macro cn retail
sec macro cn retail --begin 202601 --end 202609
sec macro cn retail --begin 202001 --end 202609 --json
sec macro cn retail --refresh
sec macro cn retail --no-cache
```

本功能采集全国社会消费品零售总额的四个指标，不混入同目录下的限额以上单位消费品零售额，也不扩展到城乡、餐饮、商品类别、网上零售或服务零售额。官方目录路径为“月度数据 → 国内贸易 → 社会消费品零售总额”，动态发现目录和指标 ID 后一次查询四项。

| JSON 字段 | 官方指标 | 单位/含义 |
| --- | --- | --- |
| `amount` | 社会消费品零售总额当期值 | 亿元；当月金额 |
| `ytd_amount` | 社会消费品零售总额累计值 | 亿元；年初至该月累计金额 |
| `yoy_percent` | 社会消费品零售总额同比增长 | %；当月名义同比 |
| `ytd_growth_percent` | 社会消费品零售总额累计增长 | %；年初至该月名义累计同比 |
| `ytd_period` | 累计所属期 | 如 `202601-202602`，不表示单独 2 月 |

JSON 显式保存 `amount_unit: "亿元"`、`growth_unit: "%"`、`price_basis: "nominal"`、`seasonally_adjusted: false`。金额为现价，增速未扣除价格因素；不将同比误标为实际消费增长，不将已是增速的数值再减 100。社零包含实物商品零售和餐饮收入，不能等同于覆盖全部服务的居民消费总支出。定义和名义口径见[国家统计局发布](https://www.stats.gov.cn/sj/zxfb/202603/t20260316_1962786.html)。

2026-10-26 核验时，2026 年 1 月四项为空；2 月当月金额与单月同比为空，1—2 月累计金额为 86078.9 亿元、累计同比为 2.8%。程序保留原始精度和空值，并在 2 月标注“1—2月合并累计，不是2月单月值”。不复制累计值为当月值，不拆分 1—2 月，不利用累计值相减推算缺失当月金额，也不利用累计增速相减推算单月增速。历史年份按实际返回保留，不强行清空所有 1、2 月数据。

同比增速采用官方可比口径，调查范围和历史数据可能调整，不能仅根据本次下载的跨年金额自行重算并覆盖官方增速。负增速与真实零值保留；金额为负、非法数值、重复月份/观测值，以及元数据截断或缺少必需系列时返回错误。接口未返回整个月时不补虚构记录，返回月份中的缺失字段以 JSON `null` / 表格 `—` 展示。

缓存、默认月份范围及刷新参数与其他发布库指标相同。JSON 同时保留地区、目录及四个系列 ID、来源、抓取时间。未取得逐条公布时间，不用月份或抓取时间代替；本功能不新增历史修订档案或季调环比采集。

`retail-catalogs.json`、`retail-series.json`、`retail-values.json` 为 2026-10-26 获取并精简的官方样本，观测覆盖 2026 年 1—9 月；保留同目录限额以上系列用于验证不会误选。测试覆盖四项映射、1—2 月口径、零值、负增速、缺失值、元数据异常、重复/非法记录、缓存命中/刷新、取消请求，以及中文表格和月份参数。

## 城镇调查失业率

```bash
sec macro cn unemployment
sec macro cn unemployment --begin 202001 --end 202609 --json
sec macro cn unemployment --begin 202306 --end 202401 --age-groups
sec macro cn unemployment --age-groups --json
sec macro cn unemployment --refresh
sec macro cn unemployment --no-cache
```

默认仅查询全国城镇调查失业率；`--age-groups` 同时查询 16—24 岁、25—29 岁、30—59 岁及旧 25—59 岁四个年龄组。月份参数、六小时缓存、JSON 和刷新方式与其他宏观查询一致。

动态选择“月度数据 → 城镇调查失业率 → 城镇调查失业率”，精确匹配所选指标，一次获取全国值及可选年龄分组。不混入同目录的 31 个大城市、户籍分组失业率或企业周工作时间，也不以其他分组填补全国值缺口。

| `indicator` | 指标 |
| --- | --- |
| `urban-surveyed` | 全国城镇调查失业率 |
| `age-16-24` | 全国城镇 16—24 岁劳动力失业率 |
| `age-25-29` | 全国城镇 25—29 岁劳动力失业率（不含在校生的新分组） |
| `age-30-59` | 全国城镇 30—59 岁劳动力失业率（不含在校生的新分组） |
| `age-25-59` | 全国城镇 25—59 岁劳动力失业率（旧分组） |

数值为失业率水平，单位 `%`，不是同比增速、PMI 或登记失业率。失业人口需符合工作搜寻、可以开始工作等条件，未就业的所有人不等于失业人口。全国总体包含符合劳动力定义的在校生，不能直接套用新年龄分组“不含在校生”的口径。[计算方法](https://www.stats.gov.cn/zs/tjws/zytjzbqs/tcsyl/202411/t20241115_1957491.html)、[全国与分年龄口径说明](https://www.stats.gov.cn/hd/lyzx/zxgk/202406/t20240619_1955075.html)。

### 年龄分组断点

当前官方元数据中，16—24 岁同一个系列 ID 同时包含新旧口径，指标名称未直接注明“不含在校生”，但官方注释明确“2023年12月起，失业率年龄分组进行了调整，往月数据包含在校生”。因此程序根据所属期标记口径，不仅依赖名称或 ID：

| 所属期/指标 | `definition_version` | `student_scope` |
| --- | --- | --- |
| 全国值，各月 | `national-surveyed` | `included-if-in-labour-force` |
| 16—24 岁，至 2023 年 6 月 | `legacy-including-students` | `included-if-in-labour-force` |
| 16—24 岁，2023 年 7—11 月 | `publication-paused-202307-202311` | `not-applicable` |
| 16—24 岁，自 2023 年 12 月起 | `excluding-students-since-202312` | `excluded` |
| 新 25—29 岁、30—59 岁 | `excluding-students-since-202312` | `excluded` |
| 旧 25—59 岁 | `legacy-including-students` | `included-if-in-labour-force` |

新分组从 2023 年 12 月所属期起有值，在 2024 年 1 月恢复发布时公布，**不能把公布月份误当成数据所属月份**。[国家统计局调整说明](https://www.stats.gov.cn/xxgk/sjfb/zxfb2020/202401/t20240117_1946644.html)。新分组较早月份以及旧分组停止发布后的缺口保持为空；程序不插值、不替换、不将旧 25—59 岁拆成新组或与新组拼接，也不将 2023 年 6 月的 21.3% 与 12 月的 14.9% 直接解释为同口径改善。

JSON 的 `series_key` 为 `indicator:definition_version`，用于区分已知口径版本。年龄分组历史分析必须结合该字段，不能仅按官方 `series_id` 或 `indicator` 连线、计算跨断点变化。`series_key` 只标记已核验的这次口径变化，不承诺捕获未来所有统计方法调整。

每条 JSON 保留地区、所属期、失业率、单位、未季调标识、口径版本、在校生范围、官方目录/系列 ID、名称、来源、抓取时间和缺口说明。真实零值保留；缺失字段为 `null` / 表格 `—`；未返回的整个月不补虚构记录。重复观测、异常数值（非有限数或超出 0—100）、缺少所选元数据或指标列表被截断时返回错误。官方未提供逐条公布时间，不用抓取时间代替；历史修订档案限制同上。

`unemployment-*.json` 样本于 2026-10-26 获取，精简后保留 2023 年 6 月、7 月、11 月、12 月及 2024 年 1 月、9 月的口径边界数据和官方系列注释。测试覆盖全国/年龄选项、口径版本及可比序列隔离、暂停期、旧年龄组、零值/缺失/异常值、元数据异常、缓存命中/刷新、取消请求和表格展示。

## 实际 GDP

```sh
# 默认截至北京时间上一个已结束季度，共8个季度
sec macro cn gdp

# 起止季度包含端点，格式为YYYYQ1至YYYYQ4
sec macro cn gdp --begin 2025Q1 --end 2026Q3
sec macro cn gdp --begin 1992Q1 --end 2026Q3 --json
sec macro cn gdp --refresh
sec macro cn gdp --no-cache
```

仅指定 `--end` 时，开始季度默认向前7个季度，且不早于1992Q1。上一个已结束季度未必已发布，缺失值照常保留；显式查询未发布季度也不会填入估计值。季度命令独立解析季度范围，不使用其他命令的月份默认值。

### 官方季度数据源

使用同一新版发布库，目录请求 `/new/queryIndexTreeAsync` 的 `code=2` 表示季度数据（现有月度查询为 `code=1`）。按名称发现“季度数据 → 国民经济核算”及以下三个目录，再通过 `/new/queryIndicatorsByCid` 按完整名称选择指标，不固定目录或系列ID：

| 目录 | 指标 | 含义 |
| --- | --- | --- |
| 国内生产总值（不变价） | 当季值、累计值（亿元） | 官方实际量原始水平；按不同基期分段计算 |
| 国内生产总值指数 | 上年同期=100的当季值、累计值 | 实际同比指数；分别减100得到当季同比、年初累计同比 |
| 国内生产总值环比增长速度 | 环比增速（%） | 官方季调实际环比，未年化 |

请求 `/stream/esData`，全国地区码 `000000000000`，每个目录一次请求，共三次数据请求；季度所属期编码为 `YYYY01SS` 至 `YYYY04SS`，如 `202501SS-202603SS`。不逐季请求，不从累计增速相减得到单季同比，也不从不同基期的金额计算同比或环比。

[国家统计局季度核算发布稿](https://www.stats.gov.cn/sj/zxfb/202610/t20261020_1965658.html)同时展示现价金额与不变价增长速度。本功能专门选择发布库的“不变价”金额，不能用发布稿中的现价金额代替。其方法说明也明确季调环比及历史修订；[2025年三季度核算说明](https://www.stats.gov.cn/sj/zxfb/202510/t20251021_1961646.html)介绍了不变价固定基期与每五年更换基期的方法。

### 口径与版本限制

官方系列元数据注明“不变价数据按不同基期分段计算”，未给出逐季基期映射。因此 `real_base_year=null`，保留源注释，不将整个金额历史标成统一基年或可无缝比较的实际量序列。当前不根据年份硬编码推断基期，也不据这些金额跨基期计算增速。

截至2026-10-27实测1992Q1至2026Q3：当季与累计同比指数自1993Q1有值，不变价当季/累计金额自2007Q1有值，季调环比自2011Q1有值。这是当前数据快照中的覆盖，不保证未来修订后仍完全相同。请求范围内每个季度均返回一项，源空值、单个系列缺口或整个季度未返回均保留null，真实零值仍为0。

JSON顶层包含地区、季度频率、实际价格口径、金额/增速单位、请求范围和 `data_version="latest-available"`。接口未提供可重建历史初值/核实值的版本档案、逐季修订编号或实际公布时间，所以 `revision_id`、`published_at` 为null，不将抓取时间当作公布时间，也不声称这些历史值是当时已知数据。

`series` 保存五个源指标的键、目录ID、系列ID/名称、单位、季调标识、原始 `i_annotation`、来源接口地址及本批数据 `fetched_at`。`observations` 按季度升序，包含：

- `real_value`、`real_ytd_value`：不变价当季/累计金额，亿元，未季调；不能直接跨基期比较。
- `yoy_index`、`ytd_yoy_index`：官方原始上年同期=100指数。
- `yoy_percent`、`ytd_yoy_percent`：上述指数减100的计算值。
- `qoq_percent`：官方季调环比（%），未年化，不自行由金额计算。
- `status`：五个源值均存在时为 `complete`，存在缺失时为 `missing-values`。

表格显示季度、当季实际同比、累计实际同比、季调环比以及两项不变价金额，空值为 `—`。当前不提供中美GDP默认增速排名；美国环比年化增速与中国非年化环比不能直接混用。

### 缓存与验证

复用NBS六小时原始JSON缓存，`--refresh` 强制刷新，`--no-cache` 不读写磁盘。不同季度范围对应不同请求缓存，系列抓取时间随缓存保留。任一目录、系列或网络请求失败时整次查询报错，不静默返回部分指标。GDP版本说明仅指抓取时可见数据，缓存有效期内可能还未反映新发布或修订。

`testdata/gdp-*.json` 来自2026-10-27核验的官方目录、元数据及值响应；值样本保留1992Q1、1993Q1、2007Q1、2011Q1和2025Q1至2026Q3，包含早期缺口。测试覆盖季度编码/默认值、动态目录和精确系列选择、原始指数与计算同比、负环比、零值/缺失、重复及非法数据、缓存/刷新/不缓存、取消请求和命令JSON/表格输出。
