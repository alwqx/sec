# 人民银行宏观数据采集

## PBC 的含义

`PBC` 是 **People's Bank of China** 的缩写，即中国人民银行。`provider/pbc` 按官方数据来源分包，负责请求、编码处理、年度目录发现、统计表解析和缓存。

- 官方统计数据入口：<https://www.pbc.gov.cn/diaochatongjisi/116219/116319/index.html>
- 2026 年社融目录：<https://www.pbc.gov.cn/diaochatongjisi/116219/116319/2026ntjsj/shrzgm/index.html>

## 社会融资规模

```bash
sec macro cn financing
sec macro cn afre --begin 202601 --end 202609
sec macro cn financing --begin 202609 --end 202609 --details
sec macro cn financing --begin 202001 --end 202609 --json
sec macro cn financing --refresh
sec macro cn financing --no-cache
```

`AFRE` 是 Aggregate Financing to the Real Economy 的缩写，`afre` 为 `financing` 的别名。默认截至上一个自然月，开始月份为截至月份前 11 个月；`--begin`、`--end` 使用 `YYYYMM`。

默认表格展示社融存量、存量同比、当月增量和年初累计增量。`--details` 额外展示融资结构，JSON 始终包含全部采集分项及来源元数据。

### 来源与解析

程序从统计数据入口动态发现所选年份的“统计数据”页面，再进入“社会融资规模”目录，按完整标题选择全国增量/存量表的 HTML 链接；不将地区表、PDF 或表格下载按钮串列。附件地址由官网发现，不按日期或文件名猜测。

官方 HTML 是电子表格导出的表格，解析时展开 `rowspan`、`colspan`：

- 增量表按月份逐行，融资渠道逐列。
- 存量表按渠道逐行，每个月包含存量与同比增速两列。
- 按页面声明解码 UTF-8、GB2312/GBK 等编码。
- 识别金额单位、月份、总量和融资渠道；单位、布局、必需总量行异常时返回错误。
- 保留表下注释，包括编号形式的统计范围调整说明；不把编号注释当作金额。

2026 年当前原始表：

- [社会融资规模增量表](https://www.pbc.gov.cn/diaochatongjisi/attachDir/2026/10/2026101417443343908.htm)
- [社会融资规模存量表](https://www.pbc.gov.cn/diaochatongjisi/attachDir/2026/10/2026101417444554195.htm)

这些是官网当前附件链接，后续更新可能替换。2020、2025、2026 年样本用于离线测试；真实接口验证覆盖 2020 年 1 月至 2026 年 9 月。

### 统计口径与累计值

社融存量表示期末实体经济从金融体系获得的融资余额；增量表示一定期间获得的融资额。二者含义不同，程序分别读取官方表，不以存量差额替代月度增量。

金额输出统一为**亿元**。2026 年官方增量表原单位为亿元，存量表原单位为万亿元；后者乘 10000 后输出。`flow_source_unit`、`stock_source_unit` 保留原单位，缓存保留原始 HTML；存量同比直接使用官方表中的百分数。

累计增量为**计算值**：读取同一年度完整增量表，从 1 月至所属月份按渠道求和。即使只查询 9 月，也必须包含该表 1—8 月数据；跨年重新累计。任何必要月份或分项缺失时，该累计值为 `null`，不跳过缺口、不补零。`ytd_method` 为 `sum-of-published-monthly-flows`，`ytd_period` 明确累计范围。

该求和结果保留当前年度表内的修订口径与精度，可能与某次新闻稿的四舍五入累计值不同。它不是另行抓取的官方累计发布值，也不能替代按可比口径公布的同比多增/少增。

2026-10-26 核验时，9 月存量为 468.17 万亿元，存量同比 7.1%，当月增量 35476 亿元，同一年度表 1—9 月增量求和为 274589 亿元。

### 融资结构

当前表提供十个主要分项：人民币贷款、外币贷款（折合人民币）、委托贷款、信托贷款、未贴现银行承兑汇票、企业债券、政府债券、非金融企业境内股票融资、存款类金融机构资产支持证券、贷款核销。

每个分项保留存量、存量同比、月度增量和累计增量；负增量表示净减少等实际融资变动，不作为异常。分项不完整覆盖所有余额调整，且源表存在精度和口径差异，程序不假定展示分项之和一定等于总量。

历史“地方政府专项债券”与较新“政府债券”使用不同的渠道键；不把它们强行合为同一历史序列。未识别但位于数据区域的新渠道保留为 `other:<原表名称>`，供进一步核验。

社融中的“人民币贷款”是对实体经济发放贷款的社融口径，与后续 TODO 的金融机构人民币贷款统计范围不同；不能直接视为同一序列。统计范围调整需结合 `flow_notes`、`stock_notes` 及各自原表追溯。

### JSON、缺失值与缓存

JSON 包含：

- 全国地区、所属月、累计所属期、统一单位、总量与结构数值。
- 增量/存量原始表链接、原单位、各自抓取时间及统计注释。
- 累计计算方法、缺口说明。

未发布月份常预留在年度表末尾；总量各项均为空时不生成虚构观测。已发布月份的缺失指标保留 `null` / 表格 `—`；真实零值保留。重复月份、重复观测或非法数值返回错误；跨年度某一表失败时不输出貌似完整的部分结果。缺少所选年份或 HTML 表链接时也明确报错。

缓存位于 `~/.sec/cache/pbc/`，按 URL 保存原始响应字节、内容类型及 UTC 抓取时间，有效期六小时；原始字节在 JSON 中以 Base64 编码保存。临时文件写入后原子重命名，HTTP 错误不写入缓存。`--refresh` 重新请求，`--no-cache` 禁用磁盘缓存。

年度表可能在后续月份或年份修订，因此历史数据是当前可获得版本。抓取时间不是公布时间，不根据附件文件名伪造逐条公布日期；当前实现不保存完整修订档案，不能用于重建历史某日已知数据。官方目录与 HTML 布局无开发者 API 兼容承诺。
