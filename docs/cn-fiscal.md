# 中国财政收支

`mof` 指中国财政部（Ministry of Finance）。`provider/mof` 直接采集财政部全国财政收支专题及国库司正式发布稿。

```bash
go run . macro cn fiscal
go run . macro cn fiscal --begin 202501 --end 202609
go run . macro cn fiscal --begin 201501 --end 201505 --budget general --json
go run . macro cn fiscal --begin 202609 --end 202610 --budget fund --no-cache
```

## 采集范围

| 键 | 全国指标 | 预算类型 |
| --- | --- | --- |
| `general-revenue` | 一般公共预算收入 | `general` |
| `general-expenditure` | 一般公共预算支出 | `general` |
| `fund-revenue` | 政府性基金预算收入 | `fund` |
| `fund-expenditure` | 政府性基金预算支出 | `fund` |

四项均为全国总量、当年年初至所属月末的**累计名义流量**，单位亿元，未季调、未年化。它们不是存款余额、GDP或居民人均收支，不与中央本级、地方本级或税收分项混用。两本预算分开列示，不把二者直接相加称为完整政府收支；政府性基金支出可以包含用地方政府专项债券收入安排的支出。

`ytd_yoy_percent` 是金额主句中直接公布的累计同比，`comparable_ytd_yoy_percent` 单独保存另列的同口径累计同比；2022年另公布的扣除留抵退税因素后的同比保存在 `tax_refund_adjusted_ytd_yoy_percent`，自然口径仍放在 `ytd_yoy_percent`。例如2015年有政府性基金转列一般公共预算的范围调整，主同比与同口径同比不能混为一项。终端在另有同口径或留抵退税调整后同比时显示 `*`，详细数值与原文通过 JSON 查看。

官方“同比增长1.1倍”换算为110%，保留原文；仅称“与去年同期基本持平”而没有精确百分比时，增长字段保留 `null` 并说明原因，不伪造为0。真实数值零与缺失分开处理。

本次只采集官方累计金额及累计同比。即使历史稿同一段同时列出当月与累计值，也只选择累计金额主句，不把当月值误当累计值。不通过累计增速相减计算当月，不通过累计金额差额假定可比当月数。

## 月份、历史覆盖与缺口

支持自201501起的现代一般公共预算口径，早期目录也有财政报告，但未在本命令中扩展或拼接旧口径。默认北京时间上个月及前11个月，默认起点在201501截短；显式更早、倒序、非法月份和晚于当前北京时间月份的请求报错。

报告标题可能为“1—2月”“一季度”“上半年”“前三季度”“某月”或“全年”。即使标题仅写“11月”，仍按正文提取1—11月累计值。年度报告记入12月，`ytd_period` 为当年01月至12月；年度初步执行数不替换为后续预算或决算数字。1月通常没有单独报告，不拆分1—2月合并数。

财政部专题不是无缺口历史档案。2026-10-29核验：专题中2015年6—12月没有对应报告链接；这些期间及其他未收录、未提供的期间保留 `missing-release`，四项数值为空，不以本地推算或其他口径数据填补。`missing-release` 不证明官方从未发布，也不代表数值为零。当前核验最新所属期为202609。

`status=complete` 表示该报告的四项累计金额和精确增长均可解析；`missing-values` 表示如“基本持平”这样的精确百分比未提供。每个指标保留 `raw_paragraph` 和解释说明。`--budget all|general|fund` 控制输出预算类型。

## 来源、公布时间和修订

- [财政部全国财政收支专题](https://www.mof.gov.cn/zhengwuxinxi/redianzhuanti/quanguocaizhengshouzhiqingkuang/)：读取真实分页总数，逐页扫描全部目录，避免置顶或乱序旧稿造成提前终止。仅接受财政部官网链接，并将旧HTTP链接升级为HTTPS。
- 正式发布稿位于财政部国库司 `gks.mof.gov.cn/tongjishuju/`。标题所属期、金额单位、主句、全国口径及重复项在使用和缓存前校验；解析异常直接报错，不静默返回部分成功结果。
- `published_date` 保存官方目录日期；若稿件 `PubDate` 元数据提供北京时间精确时间，则另存 `published_at`。缺少精确时间时为 `null`，不造午夜时间。
- `fetched_at` 为实际抓取时间，不能替代公布时间。`data_version=current-visible-release` 表示抓取时可见正文；`revision_id=null`，不宣称提供历史时点修订档案。
- 两本预算的收入减支出不等同于官方财政赤字。本命令不根据这四项推算赤字，也未采集社保基金预算等其他预算。

## 缓存与测试

原始HTML以URL散列保存在 `~/.sec/cache/mof/`，缓存六小时；`--refresh` 跳过读取并刷新，`--no-cache` 不读写磁盘。目录和报告在命中及写入前均进行语义校验；来源不符、过期或未来时间戳的缓存不复用，坏缓存尝试重新下载。异常刷新不覆盖对应的有效缓存，网络失败不静默退回过期数据。

`provider/mof/testdata/` 保存由2026-10-29下载页面提取的精简样本：目录保留全部发布链接、日期及分页总数，报告保留标题、公布时间和完整正文段落；移除导航、样式和无关脚本，每个HTML压缩为一行，覆盖早期重分类、仅文字说明持平、年度回顾段、同段月度与累计数、倍数增长、旧月份标题、年度和最新报告。测试覆盖目录分页、缺口、四项数值与口径、负增长、非法或重复金额、缓存保护、取消请求及命令输出。

```bash
go test ./provider/mof ./cmd/macro -run Fiscal -count=1
```
