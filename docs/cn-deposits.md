# 中国住户人民币存款

```bash
go run . macro cn deposits
go run . macro cn deposits --begin 202601 --end 202609
go run . macro cn deposits --begin 202609 --end 202610 --json --no-cache
```

## 采集范围和口径

`provider/pbc/deposits.go` 复用中国人民银行（People's Bank of China，PBC）官方目录，选择**金融机构人民币信贷收支表**的“住户存款”，不是“存款类金融机构”表、全部人民币存款、本外币存款或外币存款。金额统一为亿元，名义、未季调、未年化。

- `balance`：住户人民币存款月末余额，属于存量，不是居民收入、消费、当月新增储蓄或财富总额。
- `demand`、`time_and_other`：同表同一住户部门下的活期、定期及其他存款。解析器在离开住户部门后停止取分项，避免误取企业的同名行。
- `computed_yoy_percent`：`(当月余额 / 严格上年同月余额 - 1) × 100`，另存 `year_ago_base` 的原值、原字符串、来源、抓取时间与注释。缺少基数或基数为零时为空，不跨到最近月份，不年化。
- `reported_household_yoy_percent`：只接受报告明确公布的住户存款余额同比。现核验报告仅提供全部人民币存款的同比，不能将其套给住户，本字段保持 `null`。终端明确显示“计算同比”。住户官方可比同比来源继续单列 TODO。
- `monthly_flow`、`ytd_flow`：来自金融统计数据报告中的人民币存款分部门新增额，可以为负或零。不以余额相减代替新增，余额还可能受统计调整、修订影响。

计算同比基于当前年度表的可见余额，**未另作统计范围或修订调整，不是官方可比同比**。2023 年起部分非存款类机构纳入金融统计范围；表注与报告统计范围说明分别保留，不擅自修正旧表或把不同历史版本称为统一可比口径。

## 报告期间和缺失

同一份报告可能同时包含累计新增、月度新增、全币种及外币数字，程序限于人民币存款段落中的“住户存款”：

| `monthly_flow_method` | 含义 |
| --- | --- |
| `published-monthly` | 报告直接提供住户当月新增额 |
| `january-published-ytd` | 1 月官方累计即当月新增 |
| `difference-of-rounded-ytd-releases` | 同年严格相邻两份累计报告之差，是近似计算值，`monthly_flow_approximate=true`，终端显示 `≈` |
| `unavailable` | 无直接月度值且缺少相邻累计基数，保持 `null` |

报告只提供当月新增时，不伪造全年累计；年报只提供全年住户新增而没有 11 月累计时，不用 11 月单月值相减。不同年份不相减；不跨报告缺口。报告中的“同比多增”不是本期新增，不用于填充值。

2026-10-29 实时核验：2026-09 住户余额为 1752979.27 亿元、严格上年同月为 1639847.95 亿元；报告累计新增为 93900 亿元，8 月累计为 69900 亿元，由此得到近似 9 月新增 24000 亿元。余额差与报告新增不保证相同。2026-10 的未提供数据保留为空，不填零。

默认范围为北京时间上月及此前 11 月。查询起点暂设为 202101，2020 年官方余额表用于同比基期；更早报告和表结构尚未系统核验，不声称覆盖更早历史。默认起点会截短，显式更早、无效、倒序或晚于当前北京时间月份的请求报错。

逐月保留整个请求窗口，即使报告目录缺失某月。余额、同比和流量各自保留空值，JSON `note` 说明缺口；终端五列，不加入逐条长说明。某份必需年度余额表无法获取时整次查询报错，不静默给出不完整结果。

## 来源、修订与缓存

从人民银行统计数据目录依次发现年度页、金融机构信贷收支统计和人民币 HTML 表，额外读取前一年度的严格同比基期，不硬编码当前附件链接。金融统计报告按现有目录分页发现，共用目录遍历，但存款正文解析不依赖贷款段落是否完整。

`data_version=current-visible-revision` 表示当前抓取时可见版本。余额表逐期发布时间和历史修订编号不可得，`balance_published_at`、`revision_id` 为 `null`。报告网页 `PubDate` 保留在 `report_published_date`，只有日期时不补时分秒；余额、报告及基期分别保留实际抓取时间，不能当作公布时间。

原始 HTML 响应复用 `~/.sec/cache/pbc` 六小时缓存。余额原字符串在 `raw_values`，报告提取的人民币存款段落在 `raw_report_text`；原始完整响应在磁盘缓存。`--refresh` 强制刷新，`--no-cache` 不读写磁盘。新余额表和报告解析在命中及写入前进行语义校验，坏缓存重新下载，异常刷新不覆盖对应的有效缓存；不静默回退过期数据。

离线样本包括官方 2020、2025 年余额表（去除 Excel 样式，保留表格内容、合并单元格和注释；每个HTML压缩为一行），复用既有 2026 表和金融统计报告样本。测试覆盖总量与住户区别、部门分项、同比基数、单月/累计、负值/零/缺失、非法表格、异常刷新及坏缓存恢复、日期与命令输出。
