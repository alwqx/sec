# 宏观指标一览

`sec macro cn`、`sec macro us` 及 `sec bond` 已实现指标的频率、字段和官方来源。覆盖范围和限制见各指标文档，`--standard-json` 的口径见[统一导出文档](macro-standard.md)，汇率见[汇率文档](forex.md)，命令分类和 Desktop 位置见[命令与 Desktop 功能对照](commands.md)。

## 中国

| 数据 | 频率 | 采集字段 | 官方来源 |
| --- | --- | --- | --- |
| CPI、核心 CPI、PPI | 月度 | 同比、环比及原始相对指数；核心 CPI 历史目录缺口保留空值，见 [NBS 文档](nbs.md) | 国家统计局 |
| 制造业 PMI | 月度 | 总指数、生产、新订单、新出口订单、从业人员分项；保留季调扩散指数水平，见 [NBS 文档](nbs.md#制造业-pmi) | 国家统计局 |
| 非制造业商务活动指数 | 月度 | 总指数、服务业、建筑业及九个全国分项，共 12 项；见 [NBS 文档](nbs.md#非制造业商务活动指数) | 国家统计局 |
| 规模以上工业增加值 | 月度 | 单月同比、累计同比及发布稿可检索的季调环比；区分 1—2 月合并发布及环比历史覆盖限制，见 [NBS 文档](nbs.md#规模以上工业增加值) | 国家统计局 |
| 社会消费品零售总额 | 月度 | 当月金额、同比、累计金额与累计同比；保留亿元单位、名义口径与 1—2 月合并缺口，见 [NBS 文档](nbs.md#社会消费品零售总额) | 国家统计局 |
| 城镇调查失业率 | 月度 | 全国值及可选年龄分组；区分在校生口径、2023 年暂停期与新旧可比序列，见 [NBS 文档](nbs.md#城镇调查失业率) | 国家统计局 |
| 社会融资规模 | 月度 | 存量、存量同比、当月增量、融资结构；累计增量按同一年度表月度增量求和并标记计算值，见 [PBC 文档](pbc.md) | 中国人民银行 |
| 人民币贷款 | 月度 | 余额、官方同比、新增及居民/企业期限结构；累计报告差额标为近似月度计算值，报告缺口保留空值，见 [PBC 文档](pbc.md#人民币贷款) | 中国人民银行 |
| M1、M2 | 月度 | 余额、官方同比、M1 统计口径版本；不拼接 2025 年口径修订前后序列，见 [PBC 文档](pbc.md#m1m2) | 中国人民银行 |
| 7 天逆回购政策利率 | 事件型 | 自 2024-07-22 固定利率机制起的调整前后值、公布时间、官方生效日期；区间前基准单列，见 [PBC 文档](pbc.md#七天逆回购政策利率) | 中国人民银行 |
| LPR | 月度/调整事件 | 自 2019-08 改革起的 1 年期、5 年期以上报价、实际报价日、公布时间及相邻月基点变化；缺口不跨月计算，见 [PBC 文档](pbc.md#lpr) | 全国银行间同业拆借中心、中国人民银行 |
| 存款准备金率调整 | 事件型 | 内置 2020 年起已核验历史并增量追加：幅度/区间、机构及豁免、公布/生效日、全面/定向、额外降准与分批实施；见 [PBC 文档](pbc.md#存款准备金率调整) | 中国人民银行 |
| 中国国债收益率曲线 | 日度 | 3M、6M、1Y、2Y、5Y、10Y 中债国债到期收益率；直接查询官方 historyQuery，JSON保留其他期限与源字段，空值不补，见 [中债文档](chinabond.md) | 中央结算公司（中债） |
| 实际 GDP | 季度 | 实际同比/累计同比及原始指数、季调环比、不变价当季/累计金额；保留分段基期注释和当前可见版本，逐期基期/修订编号/公布时间不可得时为null，见 [NBS 文档](nbs.md#实际-gdp) | 国家统计局 |

其他指标：

- 7天逆回购历史：内置中国货币网可逐条追溯的操作室公告，保留公布时间、明示操作日和原始7天中标利率；覆盖2015-01-22至2024-07-19，未在公告明确时不推断操作日，与2024-07-22后的固定利率调整事件分开，见 [PBC文档](pbc.md#七天逆回购中标利率历史)。
- 存款准备金率历史：内置人民银行2018-01-01起已逐条核验的公告；保留跨句分批日期、机构范围、豁免及额外降幅，见 [PBC文档](pbc.md#存款准备金率调整)。2018年1月至4月中旬及2017年以前公告仍有缺口，继续补采。
- 货物贸易：分别采集人民币、美元进出口总额/出口/进口/差额和美元主要伙伴累计值；不跨币种换算、不从累计值生成单月值，明确海关货物范围与历史覆盖，见 [货物贸易文档](cn-trade.md)。
- 服务贸易月度总量：`macro cn services-trade` 从商务部月度接口独立采集人民币／美元进出口总额、出口、进口及官方差额；当前可见历史自2016年起，分页校验并保留月份缺口，不从累计值差分，见 [服务贸易文档](cn-services-trade.md)。
- 人民币伙伴拆分：`macro cn trade --partners-currency cny` 自动发现海关人民币主要国别／地区月报，采集官方月值、年初累计及累计同比；保留区域组织与成员重叠范围和原始注释，不由美元换算，见 [货物贸易文档](cn-trade.md)。
- 固定资产投资：从官方月报采集总量及制造业、基建、房地产开发投资的累计同比与可得金额，保留逐期范围说明及1—2月合并口径；未公布分项金额保持空值，见 [投资文档](cn-investment.md)。
- 房地产：新建商品房销售面积/金额、房屋新开工面积的累计值及官方累计同比，保留2005年销售口径变化和当前可见修订版本，见 [房地产文档](cn-property.md)。
- 工业企业经营：规模以上工业企业累计利润、期末总存货/产成品存货和应收账款及官方同比，保留历史调查频率、企业范围变化和2019年应收口径缺口，见 [工业企业文档](cn-enterprise.md)。
- 财政：财政部全国一般公共预算、政府性基金累计收入/支出与官方累计同比；区分自然、同口径及留抵退税调整后增速，保留2015年起目录缺口，不拆分1—2月或推算赤字，见 [中国财政文档](cn-fiscal.md)。
- 居民收支：全国居民人均可支配收入、消费支出现价累计金额和官方累计实际同比；保留2013年调查口径起点、实际增速缺口及年度自产自用范围差异，不拆分单季，见 [居民收支文档](cn-household.md)。
- 居民存款：住户人民币月末余额、活期/定期及其他分项、严格基期计算同比与报告新增额；保留近似月度差额、缺口和来源，见 [居民存款文档](cn-deposits.md)。

## 美国

| 数据 | 频率 | 采集字段 | 官方来源 |
| --- | --- | --- | --- |
| CPI、核心 CPI | 月度 | BLS CPI-U美国城市平均：季调/非季调指数、非季调同比、季调环比；保留缺口、脚注及计算基期，见 [BLS 文档](bls.md) | BLS |
| PCE、核心 PCE 价格指数 | 月度 | BEA经FRED转接：2017=100月度季调链式价格指数、同口径同比/月环比及基期；与消费支出金额和实际消费量分开，见 [FRED 文档](fred.md) | BEA，经FRED转接 |
| 非农就业 | 月度 | BLS CES季调非农工资岗位水平、相邻月新增及P初步标记；六小时API缓存外记录本机实际观测到的版本变化。该记录不等同于官方首次/第二次/第三次估计，完整历史修订档案另列第二批，见 [BLS 文档](bls.md#非农就业) | BLS |
| 平均时薪、每周工时 | 月度 | BLS CES私人非农全部雇员的名义税前时薪、平均支付周工时、月度水平差及同口径季调同/环比；保留基期、P脚注与缺口，见 [BLS 文档](bls.md#平均时薪与每周工时) | BLS |
| 失业率、劳动参与率 | 月度 | BLS CPS 16岁及以上非机构平民人口的官方季调比率、较上月/上年同月百分点差及严格基期；保留缺口、人口控制修订脚注和当前可见版本元数据，见 [BLS 文档](bls.md#失业率与劳动参与率) | BLS |
| 初请、续请失业金 | 周度 | 劳工部ETA经FRED转接的ICSA/CCSA季调数量、各自周六所属日期、严格周变化及连续四周计算均值；保留不同发布进度、缺口和窗口基期，见 [FRED 文档](fred.md#初请与续请失业金) | 美国劳工部，经FRED转接 |
| 实际个人消费支出 | 月度 | BEA经FRED转接的总量、商品、耐用品、非耐用品、服务；保留2017年链式美元季调折年水平、未年化同/环比和严格基期，不相加链式分项，见 [FRED 文档](fred.md#实际个人消费支出) | BEA，经FRED转接 |
| 实际可支配个人收入 | 月度 | DSPIC96实际税后收入总量、2017年链式美元季调折年水平、未年化同比/月环比与严格基期；保留当前可见修订版本，见 [实际收入文档](real-income.md) | BEA，经FRED转接 |
| 工业生产、产能利用率 | 月度 | 工业总量与NAICS制造业的2017=100季调生产指数、未年化同比/月环比，以及产能利用率和百分点差；分别保留历史起点与当前可见修订版本，见 [工业生产文档](us-production.md) | 美联储，经FRED转接 |
| 联邦基金目标利率区间 | 事件型 | 2008-12-16起的上下限、基点变化、生效日期及区间前基准；按官方声明核验公布日期/时间，不可取得时明确标记，见 [美联储政策利率文档](federalreserve.md) | 美联储官方调整表与FOMC声明 |
| 有效联邦基金利率 | 日度 | EFFR官方利率、交易所属日期、前一可用观测的基点变化、修订标记及原始字段；区分2016-03-01方法变化，不补周末/节假日，逐条公布时间不可得时为null，见 [纽约联储文档](nyfed.md) | 纽约联储 |
| 美国国债收益率曲线 | 日度 | 1 个月至 30 年期收益率；`macro us treasury` 和 `bond`、`bond-history` 都使用 `provider/bond` 的 `QueryBond`，见 [美国国债文档](bond.md) | 美国财政部 |
| 实际 GDP | 季度 | GDPC1实际水平、官方环比年化增速及计算同比/环比；可选BEA自2002Q1起的初值与后续修订增速档案，保留发布日期，档案未提供的历史实际水平为null，见 [美国GDP文档](us-gdp.md) | BEA，当前水平经FRED转接 |

其他指标：

- 进出口：月度名义出口/进口/官方差额及商品/服务分项，季度实际出口/进口/官方合计净出口及商品/服务分项；分别保留国际收支/NIPA口径、季调/折年和链式美元限制，实际分项净额未采集时为空，见 [美国进出口文档](us-trade.md)。
- 投资：月度住宅开工、建筑许可住房套数，以及季度名义/实际私人非住宅设备投资；区分季调折年水平和未年化增速，实际设备投资自2007Q1起，见 [美国投资文档](us-investment.md)。
- 房地产：月度新建单户住宅销售、当前公开快照可见的成屋销售，以及季度FHFA全交易房价指数；保留不同单位、季调和成屋短窗口限制，见 [美国房地产文档](us-housing.md)。
- 企业部门：BEA季度企业税前利润（含IVA/CCAdj）、Census月末商业库存和月度制造业新订单；分别保留频率、单位、统计总体、严格基期及修订快照，见 [美国企业部门文档](us-enterprise.md)。
- 财政收支：美国财政部 MTS 月度收入、支出及官方盈余/赤字，经 FRED 转接；保留单位、正负号、严格财年计算累计、缺口和修订限制，见 [美国财政文档](us-fiscal.md)。
- 国债每日记账发行与赎回：`macro us debt` 采集财政部DTS表IIIA，自2005-10-03起按记录日分别保留可流通／非流通发行、赎回及官方日值／月累计／财年累计；提供明确标记的日值汇总及净记账发行，保留负调整、缺失和明细，不等同于现金毛发行或公众净融资，见 [美国国债交易文档](us-debt.md)。
- 国债逐券发行日期与再发行：`macro us auctions` 按官方 `issue_date` 或 `auction_date` 查询，保留CUSIP、公告／拍卖／发行／到期日、原发行日及再发行标记，同一CUSIP的不同事件不合并，见 [美国拍卖文档](us-auctions.md)。
- 国债拍卖面值与分配：保留发行额、总中标、竞争性／非竞争性、SOMA、FIMA非竞争性及直接／间接投标人和一级交易商分项；保留是否纳入发行额的精确标记及历史空值，不任意加减合计，见 [美国拍卖文档](us-auctions.md)。
- 国债官方现金发行与赎回：`macro us debt-cash` 直接采集DTS表II转引IIIB的现金发行／现金赎回总额及官方月累计／财年累计，计算净现金流并标记推导值，不用拍卖面值或IIIA记账值替代，见 [债务现金流文档](us-debt-cash.md)。
- 国债现金口径调整溯源：保留IIIB基准和调整明细、原始方向标签、负值及新旧账户／表号，缺少总额时不自行拼算，见 [债务现金流文档](us-debt-cash.md)。
- 信用：美联储H.8月平均银行信贷、SLOOS大中型企业C&I贷款标准净收紧比例、当前征信方法家庭偿债比率；区分百分比和百分点变化、调查季度及新旧方法范围，见 [美国信用文档](us-credit.md)。
- 货币：M2SL月度季调、月平均名义余额及未年化同比/月环比，保留严格基期、缺失值与当前可见修订版本；记录2020年M1重分类及2026年扣除方法调整，见 [美国货币供应文档](us-money.md)。
