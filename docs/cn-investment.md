# 中国固定资产投资

`sec macro cn investment` 采集国家统计局当期官方月报，提供全国固定资产投资（不含农户）、制造业、基础设施和房地产开发投资四个分项的累计数据。数据不跨资产、不拼接不同经济含义的系列。

```bash
sec macro cn investment
sec macro cn investment --sector manufacturing --begin 202510 --end 202609
sec macro cn investment --sector infrastructure --begin 202512 --end 202602 --json
sec macro cn investment --sector real-estate --begin 202510 --end 202609 --refresh
sec macro cn investment --begin 202609 --end 202609 --no-cache --json
```

`--sector` 默认 `total`，可选 `total|manufacturing|infrastructure|real-estate`。`--begin`、`--end` 使用 `YYYYMM`，默认截至上个月的最近 12 个月；表格显示 `YYYY-MM`。JSON 包含分项、档案覆盖起点及逐月 `observations`，保留数值、来源 URL、公布时间、抓取时间、统计范围、可比口径说明和缺失状态。

## 来源选择与档案范围

2026-10-28 核验新版国家统计局发布库：

- `月度数据 → 固定资产投资 (不含农户) → 固定资产投资概况` 目录 ID 为 `5129067b149d4ddfbec1ffc478d35bfb`；总量指标为“固定资产投资额累计增长 (%)”，ID `7e570cf8071c4734a7d78d9f0a70fbe1`，当前目录没有全国总量金额。
- `按行业分固定资产投资增速（2018-）` 目录 ID 为 `9002859582574437a91914e0fd50166b`；制造业累计增长 ID 为 `d17718248ba14e2ba7b34d39623001ea`。当前 74 个指标没有基础设施投资合计；不能把行业增速相加构造基建增速。
- 同一行业目录的“房地产业固定资产投资额累计增长”ID 为 `30401aeb07b24782bf0e0d0c632a8557`。它与房地产开发投资的定义不同，本命令不拿该行业指标替代开发投资。

因此本命令统一采用对应官方月报，金额与增速取自同一份稿件，避免混合发布库当前修订值和另一时点发布稿金额。

动态发现入口是发布库 `new/queryCMSArticles?code=zxfb&pagenum=N&pageSize=100`，与已有工业增加值采集使用同一个目录 API 和请求缓存。2026-10-28 核验时该目录只有 206 条记录：投资月报最早可发现 **2025-09**，房地产月报最早可发现 **2025-10**。这是**当前目录可检索且已核验的档案范围**，并非经济序列历史起点，也不代表更早官方数据不存在。请求早于对应起点时拒绝查询；后续如需长历史，应另行核验官方旧站档案并单独扩展。

分页最多 100 页，找到请求的所有非 1 月月报即停止；只下载请求月份的正文。目录为空、重复分页、超过上限、请求范围内存在中间档案缺口均报错。比该分项最新可检索所属期更晚的月份保留 `status=not_published` 和空值，说明尚未检索到月报；这不能视为已确认的发布日期或日历。1 月不请求稿件，保留 `status=january_exempt`。

## 各分项实际可得值

| sector | 经济含义 | 累计金额 | 累计同比 |
| --- | --- | --- | --- |
| total | 全国固定资产投资（不含农户） | 亿元 | % |
| manufacturing | 全国制造业固定资产投资 | `null`，本轮已核验月报未公布金额 | % |
| infrastructure | 当期官方定义的基础设施投资 | `null`，本轮已核验月报未公布金额 | % |
| real-estate | 全国房地产开发投资 | 亿元 | % |

`real-estate` 从房地产市场月报中名称及单位严格匹配的“房地产开发投资（亿元）”行采集，包含住宅、办公楼、商业营业用房等开发投资，不将住宅分项当作房地产合计。本模块只读取开发投资；房地产命令另外提供商品房销售面积、销售金额及房屋新开工面积。施工、竣工、待售面积及资金来源本轮尚未采集。

总量金额取正文，累计增速同时与同稿数据表核对；制造业按数据表精确名称匹配；基建仅取正文明确公布的合计累计增速，并核验口径；房地产开发投资按表格名称、金额单位及增长率表头匹配。网页标题、所属期、分项不符，数值无效、重复表格值冲突或基建范围无法确认均报错，不猜测映射。

## 口径与断点

- 金额为现价亿元，增速为未扣除价格因素的名义同比，均未季调。本命令不采集季调环比。
- 全部数值为年初至所属月累计。1 月免报；2 月值代表 1—2 月合并累计。保留缺口，不拆分 1 月、2 月，不以累计同比相减推算单月同比，也不反推未公布金额。
- 固定资产投资总量统计范围为计划总投资 500 万元及以上的固定资产项目投资及所有房地产开发项目投资，按当期月报附注解释。房地产开发投资按当期房地产月报范围保留。
- **基建存在明确口径断点**：2025 年样本为“不含电力、热力、燃气及水生产和供应业”，`infrastructure_scope=excluding_electricity_heat_gas_water`；2026 年 1—2 月及 1—9 月样本明文包含这些行业，字段为 `including_electricity_heat_gas_water`。每条记录保留自己的 `scope`，表格直接显示范围。不同范围不可直接连接为一条同口径趋势；不相加行业增速，也不伪造重算历史。
- 官方说明根据投资统计制度方法改革、统计执法检查等修订上年同期数据，增长率按可比口径计算。`basis_note` 保留当期相关附注。不能用本期金额除以上年发布的旧金额复算官方累计同比；本实现不推断知识产权产品投资的具体改革起点。
- `published_at` 取稿件页面 `PubDate`，不用目录 `pb_time` 冒充实际公布时间：例如 2026 年 9 月投资页为 2026-10-19 10:00（北京时间），目录记录为 10:05。页面未提供公布时间时为 `null`；无效的非空日期报错。
- 当前目录没有历史发布版本/修订轨迹接口，`historical_version` 明确为 `null`。返回值代表当前可取的该期稿件内容；不能据此进行严格的历史时点回测。`fetched_at` 是抓取时间，不是公布时间。

## 缓存与验证

目录使用已有 NBS 原始响应缓存，通过 `requestValidated` 在缓存命中及网络响应保存前检查成功标记、空首页、最终无对应月报、重复分页、同月版本冲突及最终档案缺口。校验回调不修改分页状态，只有请求成功后推进状态；坏缓存会重新请求网络，错误响应不覆盖该页原有效缓存。原始 HTML 按官方 URL 单独缓存，六小时有效。不同投资分项可复用同一篇投资稿。只有通过所属期、分项、数值和范围校验的正文才写缓存。`--refresh` 跳过读取并更新缓存，`--no-cache` 不读写磁盘。过期、未来时间戳或无法解析的缓存会重新请求；上游失败时返回错误，不静默返回旧值。

离线样本仅截取官方元数据和正文，删除样式、图片并统一换行，保留数字和附注语义。覆盖年度累计、1—2 月合并、基建范围切换、房地产开发投资，并测试目录分页、档案缺口、未来月份、缓存刷新/失效及错误页不覆盖有效缓存。目录缓存回归覆盖有效缓存后刷新为空首页、重复页、同月版本冲突及末页无对应月报时该页原缓存字节不变；空/失败标记/缺失成功标记/重复分页坏缓存可以重新请求恢复。

```bash
go test ./provider/nbs ./cmd/macro -run Investment -count=1
```
