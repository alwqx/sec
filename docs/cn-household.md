# 中国居民收支

```bash
go run . macro cn household
go run . macro cn household --begin 2013Q1 --end 2026Q3
go run . macro cn household --begin 2025Q1 --end 2026Q3 --json --no-cache
```

## 指标与口径

来源为国家统计局（National Bureau of Statistics，NBS）全国季度发布库的“人民生活”，本次采集全国居民总量，不混入分城乡或旧制度序列：

| 发布库目录 | 官方指标 | JSON 字段 | 口径 |
| --- | --- | --- | --- |
| 全国居民人均收入情况 | 居民人均可支配收入累计值（元） | `income_ytd` | 现价、元/人、年初至期末累计流量 |
| 同上 | 居民人均可支配收入累计增长（%） | `income_real_ytd_yoy_percent` | 扣除价格因素后的官方累计实际同比 |
| 全国居民人均支出情况 | 居民人均消费支出累计值（元） | `consumption_ytd` | 现价、元/人、年初至期末累计流量 |
| 同上 | 居民人均消费支出累计增长（%） | `consumption_real_ytd_yoy_percent` | 扣除价格因素后的官方累计实际同比 |

**金额为现价，两个累计增速为实际增速。** 程序按官方目录的 `i_annotation` 解释增长指标，并校验“扣除价格因素的实际增速”注释；不能把这些增长字段当作名义同比。未采集官方名义同比，也不通过现价金额和 CPI 自行补算实际增速。金额和增速均未季调、未年化。

居民可支配收入包含工资性、经营净、财产净、转移净收入，可用于消费和储蓄；本命令采集人均平均数，不是中位数、家庭总收入或居民部门总金额。居民消费支出包括现金和实物消费，不能据此判断典型家庭的状况。

`YYYYQ1`、`YYYYQ2`、`YYYYQ3`、`YYYYQ4` 分别表示一季度、上半年、前三季度、全年累计。官方说明季度收支不含自产自用部分，年度收支包含，JSON 的 `includes_own_production` 对 Q4 为 `true`，其余为 `false`。因此不以全年减前三季度构造可比的第四季度数据，不计算累计环比或收入减消费所得的储蓄率。

终端保持五列：所属期、收入、收入实际同比、消费、消费实际同比。所属期直接显示“一季度／上半年／前三季度／全年”，金额为元/人；详细注释、原值、抓取时间在 JSON 中查看。

## 历史覆盖与缺失

全国城乡一体化住户收支与生活状况调查口径从 2013 年起。2026-10-29 核验发布库：两个金额系列自 2013Q1 起，实际累计同比自 2014Q1 起，最新非空期间为 2026Q3。2013 年实际增速仍返回 `null`，不拼接旧的城镇收入或农村纯收入序列。快照以后如补齐数据，按接口实际值读取，不把这次核验的缺口写成永久规则。

默认范围为北京时间上一完整季度及前七季，默认起点最早截短至 2013Q1；显式早于该起点、倒序、无效季度或晚于当前北京时间季度的请求报错。请求窗口逐季保留，接口未返回的期间或字段为 `null`，真实零不作为缺失。缺失本身不代表未发布。`status=missing-values` 表示四项中至少一项缺失。

`data_version=latest-available` 表示抓取时可见版本；发布库未提供逐期公布时间和修订编号，`published_at`、`revision_id` 为 `null`。每条序列的 `fetched_at` 仅为抓取时间，不能替代历史回测需要的实际可得时间。

## 采集与缓存

实现位于 `provider/nbs/household.go`，复用 NBS 客户端：

1. `new/queryIndexTreeAsync?code=2`：季度数据 → 人民生活 → 全国收入／支出目录。
2. `new/queryIndicatorsByCid`：通过完整指标名称选择总量与增长指标，保留标识、名称及原始注释，校验缺项、重复、分页截断与实际增长口径。
3. `stream/esData`：按两个目录分别批量请求全国（`000000000000`）数据。季度编码如 `202603SS`，不猜测或硬编码指标 ID。

响应复用 `~/.sec/cache/nbs` 下按 URL 与请求体生成的六小时缓存；`--refresh` 跳过读取，`--no-cache` 不读写磁盘。新增指标元数据、数值响应在缓存命中和写入前校验；非法季度、范围外期间、重复观测、无穷值、非数值和负金额报错，实际负增长合法。异常刷新不覆盖对应的有效响应缓存。

JSON 的 `raw_values` 按指标键保留接口原始 JSON 值，包含空字符串；整体原始响应同时保留在响应缓存中。测试样本在 `provider/nbs/testdata/household/`，为 2026-10-29 下载的完整目录、元数据及 2013Q1—2026Q4 请求响应，末季空值保留。

```bash
go test ./provider/nbs ./cmd/macro -run Household -count=1
```
