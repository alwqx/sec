# 证券行情数据

## sec quote (`sec q`)

查询证券实时行情，数据来源于 [新浪财经](https://finance.sina.com.cn)。

```
sec quote <codes>
sec q <codes>
```

### 参数

| 参数      | 说明                                                                                            |
| --------- | ----------------------------------------------------------------------------------------------- |
| `<codes>` | 证券代码，多个用逗号分隔，最多 5 个。支持 A 股（`sh601222`）、港股（`hk09988`）、美股（`msft`）。几个关键字搜到同一只证券时（如 `600036,cmb`）只显示一行，并说明「cmb 和 600036 是同一只证券（SH600036），已合并为一条」：表格模式写在表格下方（`-r` 每次刷新都显示），`--json` 放在顶层的 `notes` 里；合并不算失败 |

### 选项

| 选项             | 说明                                     |
| ---------------- | ---------------------------------------- |
| `-r, --realtime` | 实时模式，每 3 秒刷新一次（Ctrl-C 退出） |
| `-D, --debug`    | 开启 debug 日志                          |

### 实现架构

```
cmd/quote/quote.go        -- CLI 命令入口
provider/sina/sina.go     -- 证券搜索
provider/sina/quote.go    -- 行情查询（HTTP + WebSocket）
provider/sina/fund_quote.go -- 基金行情（场内交易所行情或单位净值）
```

### 数据流程

1. `resolveKeys(ctx, keys)` — 用 `sina.ResolveAll` 并发搜索证券代码，结果保持输入顺序，搜到同一只证券的关键字只保留一个并生成合并说明；找不到和搜索失败的关键字单独列出
2. `sina.QueryQuoteList(ctx, codes)` — 批量 HTTP 查询实时行情
3. `printQuote` — 使用 `tablewriter.Rich()` 渲染表格

### 输出字段

| 列名     | 说明                                 |
| -------- | ------------------------------------ |
| 时间     | 交易日期 + 时间，交易所当地时间；美股是美东时间，标“美东” |
| 名称     | 证券名称                             |
| 当前价格 | 最新价 + 涨跌额 + 涨跌幅（红涨绿跌） |
| 昨收     | 昨日收盘价                           |
| 今开     | 今日开盘价                           |
| 最高     | 当日最高价                           |
| 最低     | 当日最低价                           |
| 成交量   | 成交量（手），大数以 万/亿 显示      |
| 成交额   | 成交额（元），大数以 万/亿 显示      |
| 证券代码 | 交易所代码                           |

新浪的美股行情时间是北京时间，这里换成美东时间（自动区分夏令时），所以美股的交易日期是美东的交易日，和 `sec kline` 的日期一致；A 股、港股本来就是北京时间。`--json` 的 `trade_date`、`time` 同样是交易所当地时间，`timezone` 给出 IANA 时区：`Asia/Shanghai`、`Asia/Hong_Kong` 或 `America/New_York`。`sec info` 的美股行情时间仍是北京时间，并标明“北京时间”。

### 基金

新浪搜索把基金都返回成 `OF` 加 6 位代码，ETF、LOF 也一样，不带交易所，`sina.QueryQuoteList` 和 `QuerySecQuote` 单独处理这些代码：

- 场内基金：代码以 5 开头的按上交所、以 15、16、18 开头的按深交所，请求交易所行情（如 `sh510300`），格式和 A 股相同。
- 单位净值：同时请求新浪的基金净值 `f_<代码>`（名称、单位净值、累计净值、上一日单位净值、净值日期、份额）。场外基金只有净值；交易所没有价格（空行，或现价和昨收都是 0）时也用净值。按代码判断交易所不一定准，比如 519 开头的多是场外基金，新浪对 `sh519674` 返回全是 0 的一行，这时用净值。
- 货币基金的 `f_` 行是万份收益和七日年化收益率，上一日净值一列为空，不是净值，不返回行情（显示「—」）。
- 净值行情的价格是单位净值，昨收是上一日单位净值，日期是净值日期，没有时间、开高低和成交。表格的时间列显示「净值日期 净值」，开高低显示 `-`；`--json` 的 `nav` 为 `true`，`time` 为空，`open`、`high`、`low`、`volume`、`amount` 为 `null`。`sec watch` 和 Desktop 的净值保留 4 位小数，场内基金保留 3 位（交易所报价精确到 0.001）。
- 基金和其他证券在同一次请求里，基金的两行单独挑出来，结果仍按输入顺序。新浪没有、解析不了的基金只跳过这一只，不影响同一批的其他证券。Desktop 分批查询时按 key 数计算，可能上市的基金占两个 key，每批不超过 100 个。

### 输出示例

```bash
$ sec q sh688047,s
时间                | 名称    | 当前价格          | 昨收   | 今开   | 最高    | 最低   | 成交量  | 成交额    | 证券代码
2024-09-30 15:00:01 | 龙芯中科 | 119.62 19.94 20% | 99.68 | 106   | 119.62 | 104.5 | 825.67 万 | 9.38 亿   | SH688047
```

## sec quote-history (`sec qh`)

查询证券历史 K 线数据，数据来源于 [东方财富](https://www.eastmoney.com/)。

```
sec quote-history <code>
sec qh <code>
```

### 参数

| 参数     | 说明                               |
| -------- | ---------------------------------- |
| `<code>` | 证券代码，如 `sh601222`、`hk09988` |

### 选项

| 选项          | 说明                                                              |
| ------------- | ----------------------------------------------------------------- |
| `-b, --begin` | 起始日期，格式 `20250101`，默认最近 30 天                         |
| `-e, --end`   | 结束日期，格式 `20250131`，默认今天                               |
| `-d, --desc`  | 按日期倒序排列                                                    |
| `-f, --fq`    | 复权类型：`bfq`（不复权，默认）/ `qfq`（前复权）/ `hfq`（后复权） |
| `-D, --debug` | 开启 debug 日志                                                   |

### 实现架构

```shell
cmd/quote/quote_history.go     -- CLI 命令入口
provider/sina/sina.go          -- 证券搜索
provider/eastmoney/eastmoney.go -- K 线历史数据
```

### 数据流程

1. `sina.Search(ctx, key)` — 搜索证券代码
2. 根据交易所确定 `MarketCode`：sh→1, sz→0, hk→116, nasdaq→105
3. `eastmoney.GetQuoteHistory(ctx, req)` — 查询历史 K 线数据
4. `printQuoteHistory` — 使用 `tablewriter.Rich()` 渲染表格

### 输出字段

| 列名     | 说明                                 |
| -------- | ------------------------------------ |
| 日期     | 交易日                               |
| 名称     | 证券名称                             |
| 收盘     | 收盘价 + 涨跌额 + 涨跌幅（红涨绿跌） |
| 开盘     | 开盘价                               |
| 最高     | 最高价                               |
| 最低     | 最低价                               |
| 成交额   | 成交额，大数以 万/亿 显示            |
| 成交量   | 成交量，大数以 万/亿 显示            |
| 振幅     | 当日振幅                             |
| 换手率   | 换手率                               |
| 证券代码 | 市场代码 + 证券代码                  |
