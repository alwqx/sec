# 股票估值方法调研

## 概述

股票估值方法分为两大类：**绝对估值法**（计算内在价值）和**相对估值法**（与同类公司比较）。不同行业、不同生命周期阶段的公司适用不同的估值方法。

---

## 一、绝对估值法

### 1.1 自由现金流折现模型 (DCF)

最经典的绝对估值方法，将公司未来产生的自由现金流折现到当前。

**公式：**

```text
企业价值 = Σ (FCF_t / (1 + WACC)^t) + 终值 / (1 + WACC)^n
股权价值 = 企业价值 - 净负债
每股价值 = 股权价值 / 总股本
```

**两种 FCF：**

| 类型                   | 公式                                                 | 适用             |
| ---------------------- | ---------------------------------------------------- | ---------------- |
| FCFF（公司自由现金流） | EBIT×(1-t) + 折旧摊销 - 资本支出 - 营运资本增加      | 计算企业价值     |
| FCFE（股权自由现金流） | 净利润 + 折旧摊销 - 资本支出 - 营运资本增加 + 净借款 | 直接计算股权价值 |

**WACC 计算：**

```text
WACC = E/(E+D) × Ke + D/(E+D) × Kd × (1-t)

Ke = Rf + β × (Rm - Rf)   (CAPM)
```

**所需指标：**

| 指标                 | 来源                      | sec 现有                   |
| -------------------- | ------------------------- | -------------------------- |
| 净利润 (Net Profit)  | 利润表                    | ✓ `sec bs --type income`   |
| EBIT（息税前利润）   | 利润表（可推算）          | ✓                          |
| 折旧与摊销           | 现金流量表                | ✓ `sec bs --type cashflow` |
| 资本支出 (CapEx)     | 现金流量表                | ✓                          |
| 营运资本变动         | 资产负债表                | ✓ `sec bs --type balance`  |
| 无风险利率 Rf        | 国债收益率                | ✓ `sec bond`（美债 10Y）   |
| Beta (β)             | 市场数据计算              | ✗ 需实现                   |
| 市场风险溢价 (Rm-Rf) | 历史数据                  | ✗ 需外部数据               |
| 总股本               | 公司信息                  | ✓ `sec info`               |
| 净负债               | 资产负债表                | ✓                          |
| 税率                 | 利润表（所得税/利润总额） | ✓                          |
| 永续增长率 g         | 主观估计                  | ✗ 需假设                   |

**优缺点：** 理论上最严谨，但对假设极度敏感（WACC 和 g 的微小变动导致结果大幅波动），适合现金流稳定的成熟公司。

---

### 1.2 股利折现模型 (DDM)

假设股票价值等于未来所有股利的现值之和。

**公式：**

```text
戈登增长模型（恒定增长）：
P = D₁ / (r - g)

多阶段模型：
P = Σ (D_t / (1+r)^t) + D_n×(1+g₂) / ((r-g₂)×(1+r)^n)
```

**所需指标：**

| 指标           | 来源              | sec 现有                 |
| -------------- | ----------------- | ------------------------ |
| 每股股利 (DPS) | 分红公告 / 利润表 | ✓ `sec info --dividends` |
| 股利增长率 g   | 历史数据估算      | 可从分红历史推算         |
| 要求回报率 r   | CAPM 或主观       | 同 DCF                   |
| 派息率         | DPS/EPS           | ✓ 可计算                 |

**适用：** 分红稳定、派息率高的成熟公司（银行、公用事业）。

---

### 1.3 剩余收益模型 (Residual Income)

将内在价值分解为当前账面价值 + 未来超额收益现值。

**公式：**

```text
P = BVPS₀ + Σ ((ROE_t - r) × BVPS_{t-1}) / (1+r)^t
```

**所需指标：**

| 指标                | 来源                | sec 现有 |
| ------------------- | ------------------- | -------- |
| 每股净资产 (BVPS)   | 资产负债表 / 总股本 | ✓        |
| ROE（净资产收益率） | 利润表 / 净资产     | ✓        |
| 要求回报率 r        | CAPM                | 同上     |
| 总股本              | 公司信息            | ✓        |

**优势：** 对终值假设的敏感性低于 DCF，适合净资产较大的公司（银行、保险）。

---

## 二、相对估值法（乘数法）

### 2.1 市盈率 (P/E)

最常用的估值乘数。

**公式：**

```text
合理股价 = 合理市盈率 × 每股收益 (EPS)

P/E = 股价 / EPS
```

**三种 P/E：**

| 类型               | EPS 来源     | 含义         |
| ------------------ | ------------ | ------------ |
| 静态 P/E (TTM)     | 最近四个季度 | 已实现的盈利 |
| 动态 P/E (Forward) | 分析师预测   | 预期盈利     |
| 滚动 P/E           | 最近 12 个月 | 平滑季节性   |

**所需指标：**

| 指标             | 来源     | sec 现有                 |
| ---------------- | -------- | ------------------------ |
| 当前股价         | 行情数据 | ✓ `sec quote`            |
| EPS（基本）      | 业绩报表 | ✓ `sec valuation`        |
| 行业平均 P/E     | 外部数据 | ✗ 需外部                 |
| 历史 P/E 区间    | 历史数据 | ✓ 可从历史行情+财报推算  |
| 盈利增长率       | 历史对比 | ✓ 同上年比               |

**适用：** 盈利稳定且为正的公司。不适用于亏损公司、周期性行业顶部。

---

### 2.2 市净率 (P/B)

适用于重资产公司。

**公式：**

```text
合理股价 = 合理市净率 × 每股净资产 (BVPS)

P/B = 股价 / BVPS = 总市值 / 净资产
```

**所需指标：**

| 指标              | 来源              | sec 现有 |
| ----------------- | ----------------- | -------- |
| 当前股价          | 行情              | ✓        |
| 每股净资产 (BVPS) | 资产负债表        | ✓        |
| ROE               | 利润表/资产负债表 | ✓        |
| 行业平均 P/B      | 外部数据          | ✗        |

**P/B 与 ROE 的关系：** 高 ROE 的公司理应享有高 P/B。理想情况下 `P/B ≈ ROE / r`。

**适用：** 银行、保险、地产等重资产行业；不适用于轻资产/技术公司。

---

### 2.3 市销率 (P/S)

适用于成长型或暂时亏损的公司。

**公式：**

```text
P/S = 总市值 / 营业收入
     = 股价 / 每股营收
```

**所需指标：**

| 指标         | 来源        | sec 现有     |
| ------------ | ----------- | ------------ |
| 总市值       | 行情×总股本 | ✓ `sec info` |
| 营业收入     | 利润表      | ✓            |
| 行业平均 P/S | 外部数据    | ✗            |

**适用：** 营收稳定但尚未盈利的成长公司；周期性底部公司。

---

### 2.4 企业价值倍数 (EV/EBITDA)

比 P/E 更全面的估值乘数，考虑了资本结构和折旧政策差异。

**公式：**

```text
EV = 总市值 + 净负债 + 少数股东权益

EBITDA = EBIT + 折旧 + 摊销

合理 EV = 行业 EV/EBITDA × 公司 EBITDA
```

**所需指标：**

| 指标               | 来源       | sec 现有 |
| ------------------ | ---------- | -------- |
| 总市值             | 行情       | ✓        |
| 净负债             | 资产负债表 | ✓        |
| EBIT               | 利润表     | ✓        |
| 折旧摊销           | 现金流量表 | ✓        |
| 行业平均 EV/EBITDA | 外部       | ✗        |

**适用：** 重资产行业、并购估值、跨市场比较。

---

### 2.5 PEG 指标

将 P/E 与盈利增长率结合，衡量估值是否合理。

**公式：**

```text
PEG = P/E / 盈利增长率 (%)

合理 PEG = 1（即 P/E 应等于增长率）
```

**所需指标：**

| 指标                      | 来源        | sec 现有 |
| ------------------------- | ----------- | -------- |
| TTM P/E                   | 行情+利润表 | ✓        |
| 净利润增长率（近 3-5 年） | 历史利润表  | ✓        |
| 预期增长率                | 分析师预测  | ✗        |

**适用：** 成长型公司。PEG < 1 可能低估，PEG > 2 可能高估。

---

## 三、其他方法

### 3.1 格雷厄姆公式 (Graham Number)

本杰明·格雷厄姆提出的简单估值方法。

**公式：**

```text
格雷厄姆数 = √(22.5 × EPS × BVPS)

合理买入价 ≤ 格雷厄姆数
```

22.5 来自格雷厄姆的经验值（P/E ≤ 15 × P/B ≤ 1.5）。

**所需指标：** EPS、BVPS（`sec valuation` 可提供）。

**适用：** 防御型价值投资，快速筛选低估股票。

---

### 3.2 Peter Lynch 合理 PEGY

将 PEG 与股息率结合。

**公式：**

```text
PEGY = P/E / （盈利增长率 + 股息率）

合理 PEGY < 1
```

**所需指标：** P/E、盈利增长率、股息率（sec 均可提供）。

---

### 3.3 席勒 CAPE （周期调整市盈率）

用 10 年平均通胀调整后的 EPS 替代当前 EPS，平滑经济周期影响。

**公式：**

```text
CAPE = 股价 / 10 年平均通胀调整 EPS
```

**所需指标：** 10 年 EPS 历史（需长期数据）、CPI 数据（外部）。

---

## 四、各方法适用场景汇总

| 行业                | 首选方法                  | 辅助方法  |
| ------------------- | ------------------------- | --------- |
| 银行/保险           | P/B + ROE、DDM、剩余收益  | P/E       |
| 消费/医药（成熟）   | DCF、P/E                  | PEG、P/S  |
| 科技/互联网（成长） | P/S、PEG                  | EV/EBITDA |
| 地产/基建           | P/B、NAV                  | DCF       |
| 周期性行业          | P/B（底部）、P/E 均值回复 | EV/EBITDA |
| 亏损公司            | P/S、P/B                  | EV/EBITDA |
| 公用事业            | DDM、DCF                  | P/E       |

## 六、实现建议

### 6.1 可立即实现的功能

基于 sec 现有数据，可以立刻实现以下估值指标的计算：

```
sec valuation 600036 --method pe          # P/E + 历史 PE 带
sec valuation 600036 --method pb          # P/B + ROE
sec valuation 600036 --method ps          # P/S
sec valuation 600036 --method peg         # PEG = PE / 增长率
sec valuation 600036 --method graham      # 格雷厄姆数
sec valuation 600036 --method peers       # 同行业对比
sec valuation 600036 --method dividend    # 股息率和分红
sec valuation 600036 --method overview    # 多方法综合估值摘要
```

### 6.2 需要额外数据的功能

| 功能     | 缺什么                       | 方案                                         |
| -------- | ---------------------------- | -------------------------------------------- |
| DCF 估值 | Beta、市场风险溢价、增长预测 | Beta 可从行情回归计算；其他用默认值+可调参数 |
| 行业比较 | 行业平均 P/E、P/B            | 可接入东方财富行业数据 API                   |
| CAPE     | 10 年 EPS + CPI              | 可计算但需 10 年数据积累                     |

### 6.3 DCF 的默认参数策略

DCF 的关键假设可以让用户指定，也可以用合理默认值：

```bash
sec valuation 600036 --method dcf \
    --growth-rate 5%        \   # 未来 5 年增长率（默认：近 3 年均值）
    --terminal-growth 3%    \   # 永续增长率（默认：GDP 增速）
    --wacc 8%               \   # 折现率（默认：CAPM 自动计算）
    --margin-of-safety 20%      # 安全边际
```

## 七、`sec valuation` 口径

`sec valuation` 和 Desktop「估值」栏目使用同一个 `valuation` 包，支持沪深北 A 股和美股（口径见下方「美股」），指数、基金和港股会提示不支持。纯数字代码同时对应指数和股票时（如 `000001`），命令行会选有估值数据的股票；要指定证券请带交易所（如 `SZ000001`）。

| 指标 | 来源或算法 | 说明 |
| ---- | ---------- | ---- |
| 收盘价、总市值、总股本 | 东方财富每日估值 `RPT_VALUEANALYSIS_DET` 最新一行 | 上一个已更新的交易日收盘，不是盘中实时价 |
| PE（TTM）、PB（MRQ）、PS（TTM） | 同上，东方财富计算 | 小于等于 0 或缺失时当前值为空，不用前一天补 |
| 历史分布和分位 | 同上，2018 年至今的每日值 | 真实历史时点的倍数；小于等于 0 的交易日不计入；分位是不高于当前值的交易日占比；样本少于 250 个交易日时不计算分位和情景 |
| 每股收益、TTM 净利润、TTM 营收、每股净资产 | 由收盘价或总市值除以对应倍数反推 | 与倍数同一口径；与披露的基本每股收益不同，例如优先股股息会造成差异 |
| 年报数据、ROE | 东方财富业绩报表 `RPT_LICO_FN_CPD` | 原样展示，ROE 为最新年报加权 |
| 净利润 CAGR | 最新年报与最多 5 年前的年报 | 跨度按实际年份计算，至少 2 年；起止年份亏损时不计算 |
| PEG | PE（TTM）÷ CAGR | 亏损或负增长时不适用 |
| 格雷厄姆数 | √(22.5 × 每股收益 × 每股净资产) | 任一项小于等于 0 时不适用 |
| 情景 | 收盘价 × 假设倍数 ÷ 当前倍数 | 假设盈利、净资产和营收不变 |
| 同行业对比 | 同一表按 `BOARD_CODE` 和最新交易日查询，行业是东方财富分类 | 只比较同一交易日；小于等于 0 或缺失的公司不参与，所以中位数偏向盈利公司；少于 5 家时不计算中位数和排名；分位是中位秩：（低于当前值的公司数 + 并列公司数的一半）÷ 公司数，两头对称；排名从低到高，并列取靠前的名次；同行数据获取失败时其他结果照常，`peers` 为 `null`，`peers_note` 说明原因；分红数据同理，对应 `dividends` 和 `dividends_note` |
| 股息率 | 东方财富分红送转 `RPT_SHAREBONUS_DET`：最近完整财年的税前每股现金分红 ÷ 收盘价 | 年度分红除息后财年才算完整；最近有现金分红的财年比它晚超过一年时，用那个财年已分的现金；同一财年的中期和年度分红合计，不按除息日累计，否则一年分两次的公司偶尔会多算；分红按之后的送转摊薄到当前股本；不含送转、配股和回购；最近一次分红超过 18 个月，或有记录但没有现金分红时是真实的 0；东方财富一条记录都没有时用新浪区分：新浪有记录且近 18 个月没有已除息的现金分红是真实的 0，新浪近 18 个月有现金分红、不可用或返回空页面时股息率不可用，`dividends` 为 `null`；未除息的预案单独列出，不计入；上游每个报告期基本只有一条记录，可能缺少特别分红（如贵州茅台 2022、2023 年的特别分红），这时股息率偏低；近 5 年的分红会按除息日合计后和新浪核对，缺少或金额不同的列在 `mismatches`，不改变计算；新浪失败、超时（5 秒）或返回空页面时不核对，`mismatch_checked` 为 `false` |
| 历史股息率 | 同一定义，每个交易日按当天已知的分红、股本和收盘价计算 | 只统计有分红的交易日；分位是不高于当前值的交易日占比，样本少于 250 个交易日时不计算 |
| 近 5 个财年平均股息率 | 最近完整财年往前 5 个财年的每股分红 ÷ 5 ÷ 收盘价 | 没有分红的财年算 0；估值数据不足 5 年时不计算 |
| 分红率 | 财年每股现金分红 ÷ 分红记录里的基本每股收益 | 按报告期归属，两者都是当时的股本口径，业绩报表的每股收益可能已按后来的送转调整，不能混用；没有年度分红、每股收益小于等于 0，或财年内第一次分红和年度分红之间发生送转时不计算 |
| 连续分红 | 从最近分红的财年往前数 | 最近一次分红超过 18 个月时为 0 |
| 规则汇总 | PE、PB 历史分位，PEG，格雷厄姆数，PE、PB 行业分位，股息率历史分位 | 比较偏低和偏高的规则个数；少于两条时显示数据不足；参与比较的公司少于 10 家时不计入行业规则；未考虑公司基本面 |

DCF 是两阶段股权现金流折现：5 年增长期加永续期，现金流用 TTM 归母净利润的 70% 近似，折现结果视为股权价值，不再扣净负债。增长率留空时取 CAGR（负增长也照用），限制在 ±15%，没有可用增长率时取 5%，来源会显示在结果中；填 0 表示零增长。折现率默认 8%，须比永续增长率至少高 1 个百分点。亏损时不计算；银行、保险、证券和多元金融行业仍计算，但会提示参考价值很低。

上游的财报三表已经没有 `BASIC_EPS` 字段，所以不再用它计算估值，`sec financials` 和 Desktop 财报也不再显示这一行。

### 美股

美股（如 `sec valuation AAPL`、Desktop 中 `$AAPL` 的「估值」栏目）没有现成的每日估值表，由 `valuation/us.go` 用 SEC XBRL（`provider/edgar`）和新浪美股不复权日线计算，金额单位美元，结果的 `currency` 为 `USD`（A 股为 `CNY`）。只支持美国本土公司（按 US GAAP 以美元列报，不提交 20-F、40-F 年报，不以 ADS 上市）。

| 指标 | 来源或算法 | 说明 |
| ---- | ---------- | ---- |
| 总市值 | 收盘价 × 当时最新申报的封面流通股数（dei `EntityCommonStockSharesOutstanding`，同一份申报的各类普通股合计） | 第一份股数申报之前没有估值；封面股数超过 15 个月没有更新时（谷歌、Meta 等只按股票类别申报，companyfacts 里没有）依次改用申报封面页按类别列出的股数（见下文）和最近的单季稀释加权股数（保留申报当时的数值），都没有时不估值并说明原因；多类股票折算比例不同时，最后一天的股数和新浪当前股数相差超过 25% 时按新浪校准（已折算的类别股数除外） |
| 拆股 | 从日线跳变识别（相邻收盘价之比接近 1.5、2～8、10、15、20 倍） | 须用同一来源拆股前后的股数核对，之后还没有申报时用新浪的当前股数；无法核对时不算拆股，真实暴跌不会被当成拆股；申报新股数之前按比例调整，加权股数在申报前已追溯调整的不再调整 |
| PE（TTM）、PS（TTM） | 总市值 ÷ 最近四个连续季度的净利润、营收之和 | 季度由 10-Q 和 10-K 整理，第四季度用全年减前三季度累计；四个季度须首尾相接（间隔 80～100 天），否则当天不计算 |
| PB（MRQ） | 总市值 ÷ 最近一期股东权益 | |
| 每日可用的数据 | 每一行数值按首次申报日期可用，当天只用已经申报的数值 | 报告期后来被重述时用重述后的数字；重述较早的报告期不会让"最新"退回到较早的期间 |
| 历史分布和分位 | 最近 10 年的每个交易日 | 其余规则同 A 股 |
| 年报数据、ROE | 各财年稀释每股收益、净利润、营收，每股净资产 = 期末权益 ÷ 稀释股数，ROE = 净利润 ÷ 期末权益 | 不是加权平均 ROE；每股收益和稀释股数只按类别申报时用 10-K 利润表上所查这类股票的数（见下文） |
| 股息率 | 最近一个完整财年现金流量表支付的普通股股息（`PaymentsOfDividendsCommonStock`，没有时用含优先股的 `PaymentsOfDividends`）÷ 当前市值 | 不受拆股影响，也避开 53 周财年多算一次股息；最近申报的财年没有股息时股息率和连续分红为 0，不沿用更早财年；上方的每股分红 = 支付总额 ÷ 当前股数；历史股息率每天用当天已申报的最近一个财年 |
| 分红财年表 | 每股现金分红取年报的每股宣告股息，没有时用支付总额 ÷ 稀释股数；分红率 = 支付的股息 ÷ 净利润 | SEC 数据中没有股息记录时 `dividends` 为 `null`，提示可能不分红 |
| 行业、同行业对比 | 行业是 SEC 的 SIC 分类，SIC 6000～6799 视为金融业 | 没有同行业对比，规则汇总不计入行业规则；金融业的 DCF 提示参考价值很低 |

companyfacts 不含按股票类别申报的数值，伯克希尔、Visa 这类公司的封面股数和加权股数都只按类别申报。这时 `edgar.CoverShares` 逐份读取最近 11 年多的 10-K、10-Q 申报目录里的封面页 `R1.htm`，按股票类别维度（`StatementClassOfStockAxis`）读出各类流通股数和交易代码，表头注明 `shares in Thousands` 等单位时换算；只有交易代码没有股数的类别（债券）和其他维度（比如共同申报的子公司）不计入。申报发布后不再变化，解析结果按申报号缓存在 `~/.sec/cache/edgar/covers/v2/<CIK>/`，第一次估值要读取约 40 份申报（约 10 秒），之后读缓存；较早的申报没有封面页时缓存空结果，读取失败的申报跳过，下次重试（见下方处理规则）。只有 companyfacts 里的股数都过期时才读取，其他公司不受影响。

各类别之间的折算比例不在封面上，所以按所查这类股票折算：股数 = 这类股票的股数 + w × 其他类别股数之和，w 用最近一次申报和新浪的当前股数（新浪已按所查这类股票折算，比如 BRK.B 是全部股本折成 B 股的数量）解出。伯克希尔 1 股 A 固定折 1500 股 B，结果准确；Visa 的 B、C 类按不同且随时间变化的比例折成 A 类，用同一个 w 在历史上有误差：和 10-K 利润表上 A 类折算后的稀释加权股数相比，2015—2025 财年各年在 ±2% 以内（2017 年 −2.1%、2015 年 +1.4%，其余在 1.8% 以内）。这个差距和口径差异（全年加权平均且含期权稀释，对比某一天的流通股数）是同一量级，伯克希尔折算比例固定，也有 0.6%—4% 的差（回购），所以不按每份申报反解折算比例。

几点处理规则：

- 封面表头按单元格的 rowspan、colspan 排出每一列的日期：常见的是第一行写期间、第二行写日期，也有把某一列的日期写在第一行、跨两行的，不按出现顺序对应。
- 先判断 companyfacts 的封面股数或加权股数在最后一天是否可用，可用时不读封面，不可用时才读，估值只计算一次；同一次估值里公司资料和封面股数共用一次下载的申报列表。
- 新浪的当前股本已经包含最近一次申报之后的拆股，解 w 之前先按识别出的拆股还原到那次申报的统计日；识别拆股只用不需要折算的股数（封面股数、加权股数和所查这类股票自身的股数）。
- 能按类别折算时整段历史只用折算后的股数，不再混用各类别直接相加的封面股数或按 A 股折算的加权股数，缺少封面股数的日子不计算，避免估值序列跳变。
- 新浪的当前股本不大于这类股票自身的股数时（比如只统计了这一类），w 不是正数，无法折算，报错里说明两者的数值。
- 封面解析结果缓存在 `~/.sec/cache/edgar/covers/v2/<CIK>/`，目录带解析版本号，解析规则变化后自动重新读取；30 天内提交的申报读不到封面（SEC 可能还没生成 R 页面）或解析为空时不缓存。个别申报读取失败时跳过，结果的 `shares_note` 说明有几份没读到；`shares_note` 也说明股数是按类别折算的，命令行和 Desktop 估值页都会显示。所查这类股票按封面上的交易代码识别（不区分 `.`、`-`、`/`），2019 年以前的封面没有交易代码，按同一个类别成员对应；识别不出、没有新浪的当前股数或解出的 w 不是正数时不用这一来源。
- 这类公司的稀释每股收益和稀释加权股数往往也只按类别申报，年报表的每股收益、每股净资产会为空。最近 11 年多的年报缺这两项时，`edgar.ClassEarnings` 逐份读取 10-K 的利润表页：从申报目录的 `FilingSummary.xml` 找到报表类别里名称含 income、operations 或 earnings 的第一页（不要附注括号页和股东权益、现金流量、资产负债表，有单独利润表时不用合并了综合收益的表），按股票类别维度读出各财年的稀释每股收益和稀释加权股数（只列基本数的用基本数，比如伯克希尔），表头注明 `shares in Millions` 或 `In Millions, except Per Share data` 等单位时换算股数，单元格末尾的脚注标记忽略。所查这类股票的类别成员取自封面；利润表上成员相同的优先，没有时按类别代号（A、B、B1 等）对应（伯克希尔封面是 `CommonClassBMember`，利润表是 `EquivalentClassBMember`），同一年有多份年报时用最新申报的。年报缺每股收益或稀释股数时两项都用这一类股票的数；这类股票的股数是折算后的（每股收益 × 股数和归母净利润相差 10% 以内，比如 Visa 的 A 类、伯克希尔的等值 B 股）时才用于每股净资产和每股分红，否则只用每股收益。结果缓存在 `~/.sec/cache/edgar/earnings/v2/<CIK>/`，缓存规则和封面相同；读取失败或无法解析的年份留空，`shares_note` 说明。比如 Visa A 类 2021 财年 5.63 美元、伯克希尔 B 类 2025 年 31.04 美元，和年报一致。

外国公司暂不支持估值，返回 `valuation.ErrForeign`（Desktop 返回 422），年度财报可以查看（见命令文档）：按国际会计准则（IFRS）申报的（如 `TSM`）、最近一份年报是 20-F 或 40-F 的外国私人发行人（如 `NTES`、`BABA`）、以外币列报的公司，以及封面上存托凭证比例（`dei:EntityListingDepositoryReceiptRatio`，多数公司读不到）不是 1 的公司。原因是估值用 ADS 价格乘 SEC 封面的普通股数，ADS 和普通股的比例（网易 1 股 ADS = 5 股普通股）、财报的汇率换算都没有可靠的数据来源，估出的市值会出错。访问 SEC 使用共享配置中的联系邮箱。
