# 中国房地产：新房销售与新开工

`sec macro cn property` 采集国家统计局新版发布库的全国房地产开发企业数据，一次查询以下三项的年初累计值与官方累计同比：

| component | 指标 | 累计值单位 | 当前发布库目录 |
| --- | --- | --- | --- |
| `sales-area` | 新建商品房销售面积 | 万平方米 | 新建商品房销售面积 |
| `sales-value` | 新建商品房销售额 | 亿元 | 新建商品房销售额 |
| `starts-area` | 房屋新开工面积 | 万平方米 | 房地产施工、竣工面积 |

## 使用

```bash
sec macro cn property
sec macro cn property --begin 202601 --end 202609
sec macro cn property --component sales-area --begin 202001 --end 202609 --json
sec macro cn property --component sales-value --refresh
sec macro cn property --component starts-area --no-cache
```

月份参数为 `YYYYMM`；默认截至上一个自然月、向前查询12个月。表格把累计所属期显示为 `2026-01 至 2026-09`；JSON 保留 `period: "202609"` 和 `ytd_period: "202601-202609"`，便于程序处理。`--component` 默认 `all`，筛选单项时只请求该项的两条系列。没有额外请求时不进行跨市场或跨资产分析。

目录元数据起点为2000年1月，命令拒绝更早的范围。2026-10-28核验了销售面积2000年1月至2005年9月的真实接口返回，早期1月也为空。覆盖起点只表示目录提供的范围，不保证每个月都有值。上个月尚未发布、1月未单列、历史缺值均不补零：返回行中的空字符串等缺失表示转换为 JSON `null`、表格 `—`；接口完全没有返回的月份不构造观测行。真实零值仍显示为零。

## 指标和可比性

**销售总量包含住宅和非住宅新建商品房。** 不以住宅子目录替代全国商品房总量，也不混入现房子集、待售面积或二手房交易数据。这里“新建商品房”可以包含期房和已竣工的现房；“现房”不等于“二手房”。销售面积采用正式销售合同约定建筑面积，销售额采用相同口径的合同总价款，销售额为名义金额，未扣除价格变动。

**新开工面积属于房地产开发企业新开工房屋的建筑面积。** 以整栋房屋作为核算对象，不分割计算；开工认定采用正式破土刨槽、地基处理或打永久桩的日期。不包含以前开工后继续施工或以前停缓建后恢复施工的面积，也不等于施工面积或竣工面积。接口的当前显示名是“房地产新开工施工面积累计值/累计增长”，其内部指标名为“房屋新开工面积”；JSON 同时保留两种名称和定义。

三项均为年初至所选月份的**累计**数据，未季调，只有官方累计同比，没有单月值或单月同比。1—2月合并数据放在2月的累计所属期中；不把它解释成2月单月，也不对半分或用累计差额推算缺失的单月数据。1月空值仍可追溯，输出说明提示合并发布。

累计同比直接采集官方系列，不按当前累计值与去年发布值自行计算。国家统计局月报说明，企业范围变化、统计执法检查、项目管理及历史数据核实修订等会影响可比基数；因此同一次查询的累计值与去年的旧快照可能无法复算出官方同比。此接口提供当前版本的数据，不能恢复每一次历史发布时的原始版本。

## 名称和历史口径

本次仅动态发现并使用当前发布库的同一套系列，不与旧版 `easyquery`、其他网站或住宅系列拼接。当前目录和显示名使用“新建商品房”，但接口 `_name` 等内部字段仍使用“商品房销售面积”“房地产企业商品房销售额”。名称差异本身不足以证明某个月发生统计方法切换，代码不据此制造断点或重写历史名称；JSON 保留当前显示名、内部原名、目录ID、系列ID、定义和原始注释，便于复查。

销售系列的官方元数据另有历史注释：2005年8月以前为实际销售统计口径，2005年8月以后包括期房和现房。不能把整段历史默认为相同的新房合同口径。每条销售观测的 `scope_version` 标记为：

| 期间 | scope_version | 含义 |
| --- | --- | --- |
| 2005年7月及以前 | `before_200508_actual_sales` | 历史实际销售口径 |
| 2005年8月 | `200508_transition_unspecified` | 目录只写“以前/以后”，没有明确8月本身归属，保守标记过渡 |
| 2005年9月起 | `after_200508_presales_and_completed_sales` | 包含期房和现房的销售口径 |

不自动对跨此边界的历史同比重新计算或宣称可比；保留官方同比及注释供判断。新开工使用 `real_estate_developers` 标记开发企业口径。

## 来源、JSON和缓存

使用已有 `provider/nbs.Client` 的请求和缓存机制：动态发现“月度数据 → 房地产 → 对应目录”，在目录中精确匹配两条累计系列和单位，再请求全国（`000000000000`）数据。目录重名、元数据缺失/截断、单位或目录变化、同月同系列重复值、负累计量和非有限数值均报中文错误；不会静默改用相似指标。

接口基址是 `https://data.stats.gov.cn/dg/website/publicrelease/web/external`，调用 `/new/queryIndexTreeAsync`、`/new/queryIndicatorsByCid` 和 `/stream/esData`。目录ID和系列ID在运行时动态发现，没有硬编码历史观测值。HTTP原始响应复用NBS六小时缓存；指标元数据与观测响应在读取缓存和写入新缓存前均执行语义校验，无效刷新保留对应的有效缓存，已有坏缓存会重新请求并在校验通过后替换。`--refresh` 跳过已有缓存并更新，`--no-cache` 不读写磁盘缓存。接口错误或语义异常不输出部分结果。

JSON结果为 `observations` 和 `notes`。每条观测保留数值、累计期间、单位、未季调标记、金额价格口径、当前系列名、内部原名、目录和系列ID、元数据起点、定义、历史注释、范围版本、来源和采集时间。上游没有逐条提供发布时间或修订批次，`published_at` 明确为 `null`，`fetched_at` 仅为采集时间，不能用作经济数据公布事件的时间。`price_basis` 在销售额中为 `nominal`，面积项为 `not_applicable`。

2026-10-28抓取的官方离线样本位于 `provider/nbs/testdata/property-*.json`，包含真实目录、三项指标元数据、2026年1—9月数值和销售面积早期历史样本，用于验证解析、口径、查询参数、命令输出和缓存。2026年9月接口精度高于新闻稿整数：销售面积56482.90万平方米、销售额53798.77亿元、新开工面积34031.30万平方米，官方累计同比为-13.2%、-13.9%、-24.9%，与新闻稿按整数展示的56483、53799、34031一致。
