# 中国货物贸易数据

`sec macro cn trade` 查询中国海关货物贸易。该命令不代表货物与服务贸易总量；服务贸易通过独立的 [`macro cn services-trade`](cn-services-trade.md) 查询。

```bash
sec macro cn trade --begin 202608 --end 202608
sec macro cn trade --begin 202608 --end 202608 --partners-currency cny
sec macro cn trade --begin 202608 --end 202608 --partners-currency cny --json
```

`--partners-currency` 接受 `usd`（默认）和 `cny`，只选择截至月的伙伴统计来源；月度总量仍同时提供人民币与美元，不做币种换算。终端伙伴表展示累计值，人民币伙伴原始月值与详细范围说明见JSON。

## 数据来源与字段口径

| 字段 | 来源 | 口径 / 单位 | 覆盖 |
| --- | --- | --- | --- |
| 月度进出口总额、出口、进口、差额（人民币） | [商务部投资促进事务局统计报告](https://fdi.mofcom.gov.cn/come-datatongji-con.html?id=16127)，报告注明来源为海关总署 | 月值、年初至当月累计值、月环比、月同比和累计同比，金额单位亿元人民币 | 目录 API 分页发现题名匹配的月报；当前在线目录可列出历史报告。命令请求区间按报告所属月份筛选，不内置报告 ID。 |
| 月度进出口总额、出口、进口、差额（美元） | [商务部数据中心货物进出口月度统计](https://data.mofcom.gov.cn/hwmy/imexmonth.shtml)，页面标注数据来源为中国海关总署 | 月值、累计值、月同比和累计同比，金额单位亿美元 | 查询接口按月返回；在线月度序列可从2015年起查询。 |
| 主要贸易伙伴进出口、出口、进口 | [商务部数据中心主要贸易伙伴统计](https://data.mofcom.gov.cn/hwmy/imexCountry.shtml)，页面标注数据来源为中国海关总署 | 年初至当月累计值和累计同比，亿美元 | 页面列示的主要伙伴，不是全部国家/地区；在线查询分类覆盖自2017年起。只请求查询截至月，不由累计值差分出当月值。 |
| 人民币主要国别／地区进出口、出口、进口 | [商务部投资促进事务局转发的海关总署伙伴月报](https://fdi.mofcom.gov.cn/come-datatongji-con.html?id=16991) | 官方当月值、年初累计值及累计同比，亿元人民币 | 按目录自动发现截至月报告，校验标题、来源、发布日期、当月／累计表头及列顺序，不内置文章ID；未找到报告时保留月度总量并提示伙伴缺失。 |

国家统计局对海关贸易统计制度的说明指出，全国进出口由海关总署编制，人民币与美元均为原始统计项目，不能把一种币种的观测值当成另一币种的原始发布值。[统计指标解释](https://www.stats.gov.cn/zs/tjws/zytjzbqs/zckze/202501/t20250121_1958385.html)

人民币总量月报与伙伴月报共用商务部投资促进事务局的公开目录 API，按各自的精确题名匹配，再按报告 ID 读取正文。目录响应的 `total` 和页面记录用于分页，程序校验题名、报告来源、发布日期和内容结构；对跨页重复且元数据完全一致的目录项去重，对同 ID 元数据冲突仍报错。不会将固定 URL/ID 列表当作完整历史保证。目录按发布日期排序；只有找到同类报告所属月份早于请求开始月或到达目录末尾时才停止，不用其他类别的旧报告提前停止遍历。

人民币伙伴表保留官方原行名，包括“总值”、区域组织、“其中：”成员行及其他国家／地区，不把组织与成员相加，也不把列示行合计冒充全球总量。成员构成可能随时间变化；每次报告尾部原始注释保存在 `partner_scope`，终端仅输出简短范围提示。`partner_currency` 明确当前伙伴币种，伙伴记录保留 `total_monthly`、`exports_monthly`、`imports_monthly`、累计金额、累计同比、原文及 `published_date`（真实报告发布日期，不推算具体时分）。美元伙伴来源仍只提供累计值，不用美元数据或累计差分补人民币月值。

商务部该站点对 Go 默认 TLS 密码套件会返回握手失败。访问 `fdi.mofcom.gov.cn` 的客户端仅启用 TLS 1.2 RSA-GCM 套件以兼容站点；该配置不用于商务部数据中心的其他主机。

美元月度总量与人民币月度总量来自不同发布接口，结果在 JSON 中以 `usd` 和 `cny` 两组对象分开呈现，各自包含单位、来源 URL、抓取时间和原始字段。伙伴记录也包含单位、来源、抓取时间及原始字段。不存在来源记录的月份保留在请求序列中，相应币种字段为缺失；不插值、不跨币种换算。空值和数值零有区别。

数据响应缓存于 `~/.sec/cache/mofcom`，缓存有效期六小时。`--refresh` 强制重新请求，`--no-cache` 禁用读写缓存。报告目录和正文的 URL、数据页查询接口均由程序运行时请求，网络接口不可用时命令返回错误，不会使用伪造或推算值。

伙伴接口返回有效空数组时，月度数据照常返回，`partners` 为空并通过 `partner_note` 和终端提示说明缺失；2017 年以前或伙伴数据尚未发布的月份均按此处理。缺少 `rows`、格式错误、月份不符或 HTTP 失败仍返回错误。

## 限制

- 本指标是海关货物贸易，不含服务贸易；服务贸易使用独立命令和数据源。
- 伙伴数据只列商务部页面及报告展示的主要伙伴；组织、成员和总值存在重叠，不能相加。
- 美元伙伴指标是年初至当月累计值，不能拿相邻累计值相减冒充官方月值。
- 人民币月报页面结构或接口字段变化会触发解析错误；历史完整性取决于官方目录实际列出的报告，不作超出目录覆盖范围的承诺。
- 不生成中美指标比较或跨资产结论；汇率分析应在后续中美指标对比阶段完成。
